# 2026 전국체전 배구 공식 기록

- 발행기관: 대한체육회·대한배구협회.
- 공식 출처: https://meet.sports.or.kr/national/
- Source ID·원문 URL·무결성 해시는 `source-index.json`에 보관한다.
- 원문 파일과 내부 보관 위치는 기존 비공개 원본 보관소에서 관리하며 공개 저장소에 원문을 재배포하지 않는다.
- 참가팀의 `region`은 공식 대진표의 `SIDO_NM`을 사용한다. 팀명에서 지역을 추정하지 않는다.
- 경기결과·메달명세로 검증한 순위와 공동 3위를 유지한다.
