## 디자인

- 공통 내비게이션의 KVL 네이비, V-리그 남자부의 차콜 `#14171b`, 여자부 로즈 `#7f2f54`, 브랜드 골드 `#d6b25e`를 사용한다.
- 짧은 브랜드 제목 영역, 골드 경계선, 어두운 표 머리글, 밝은 숫자 영역으로 정보의 우선순위를 나눈다.
- 총승점은 연한 골드, 1위는 진한 골드. 팀명 열은 남녀부의 연한 테마색을 적용한다.
- 승패별 색상·그래프·팝업·호버 효과는 추가하지 않았다.
- 본문 최대 1180px, PC 2×3, 모바일 한 열, 1~6라운드 구조는 동일하다.
- 공통 Pretendard 및 기존 메뉴는 유지한다. 원래 엑셀식 색상만 이번 브랜드 시안에서 대체한다.

색상 근거는 `DESIGN_SYSTEM.md`와 더 구체적인 현행 `assets/css/kvl-competition-template-v2.css`의 PRO/WOMEN 규칙이다.

## 계산과 데이터

`build.cjs`는 v3의 `core.js`, `app.js`, `page.html`, `matrix.css`를 직접 읽는다.
계산·정렬·60초 재조회·실패 처리 코드는 수정하거나 복제하지 않았다.
새 `brand.css`와 제목의 표현만 덧붙인다. 기존 v3의 [데이터 계약·검증 한계](../vleague-matrix-v3/README.md)를 그대로 따른다.
MASTER와 운영 JSON에는 쓰지 않는다. 디자인 후속 작업이므로 오전의 MASTER 대조를 새로 수행한 것으로 보고하지 않는다.

이번 시작 시 확인한 main: `be7b530d0102a231eda2fb877cea5e3f19dcd27c`.
저장본은 해당 main의 기존 data/config에서 생성했으며 종료 남자 13경기·여자 12경기다.
페이지를 열면 main 최신 데이터로 자동 재조회하므로 화면 숫자는 촬영 이후 달라질 수 있다.

## 실행

```sh
git fetch origin main
node prototypes/vleague-matrix-v4/build.cjs origin/main
```

생성 `index.html`을 브라우저로 연다. 특정 Git ref와 출력 경로를 인자로 지정해 재현할 수 있다.
`index.html`은 gitignore이며 최종 독립 HTML을 별도 제공한다.

## 검수

- Chromium에서 남녀 × 360/390/768/1180px 8조건을 확인했다. 페이지·표 가로 넘침 모두 0px.
- 모바일 팀명/열 제목 12px, 숫자 14px. 표 바깥 폭 360에서340px, 390에서370px.
- 1180px에서 2열×3행, 모바일/태블릿에서 6행을 확인했다.
- 실제 남녀 전환 버튼: 팀명·데이터·색상 정상 변경, 전환 후 표 6개 유지.
- v4 생성 HTML에 검수된 v3 core/app 원문이 그대로 들어가는지 확인했다.
- 최신 저장본을 같은 엔진으로 계산한 남녀 데이터에서 누락/충돌 경고 0건을 확인했다.
- 이번에 자동화 코드를 바꾸거나 신규 실경기 전체 경로를 검증하지 않았다. 기존 공통 CI 제한사항은 PR #328의 v3 기록과 구분한다.
- 모바일 실물/Safari 검수는 수행하지 않았다. 화면 폭은 Chromium iframe viewport로 확인했다.
