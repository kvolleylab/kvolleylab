## 공통 디자인

`assets/js/unified-nav.js`, `assets/css/site-theme-light.css`, `assets/css/kvl-common-hero-v1.css`를 main에서 그대로 사용한다. PC 메뉴·모바일 58px 헤더·1180px 콘텐츠·HERO PC 218px(1440px 화면)·기존 홈 WebP·Pretendard 체계·흰색 카드·12px 모서리·골드 hover를 재사용했다. 남자 블루/여자 로즈는 선택·한국 랭킹 강조에만 사용하고 AVC 초록/아시안게임 딥 레드는 유지한다. 과도한 그라데이션과 별도 일러스트를 추가하지 않았다.

Drive `KVL_운영원칙_MASTER_v18` 및 최신 HERO 가이드를 읽었다. 과거 일반 `DESIGN_SYSTEM.md`의 Arial/다크 규정과 이후 날짜의 공통 라이트/Pretendard 결정에 차이가 있어, 최신 범위별 결정 및 현재 홈·국제대회·대학대회에서 확인한 공통 디자인을 적용했다. 운영 디자인 자체를 바꾼 것은 아니다.

## 공식 사실

| 대회 | 남자 | 여자 |
|---|---|---|
| AVC컵 | 2위 | 우승 |
| 동아시아선수권 | 우승 | 3위 |
| 아시아선수권 | 3위 | 6위 |
| 아이치·나고야 아시안게임 | 7위 | 4위 |

8개 모두 종료로 표시한다. 상세 기간·장소·공식 URL은 `tournaments-official.json`에 저장했다. KVA 대회 목록, AVC, Volleyball World, 일본배구협회 공식 결과를 교차 확인했다. 공식 확인되지 않은 친선대회 등은 추가하지 않았다.

남자는 아시아선수권 3위로 2027 FIVB 월드컵 진출. 여자는 2026-10-02 랭킹 경로로 월드컵 진출(10-05 공식 발표). 양쪽 모두 LA28 출전권은 아직 확보하지 않았다. 월드컵의 LA28 3자리는 기존 올림픽 확보 팀을 제외해 배정한다. 랭킹 경로는 VNL 2028 예선 종료 후 기준이며, 미대표 대륙 우선 규정이 적용된다. 아시안게임·AVC컵·동아시아는 LA28/월드컵 직접 출전권 배정 대회로 표시하지 않는다.

공식 랭킹 API의 마지막 갱신은 2026-10-15 10:40 UTC(19:40 KST). 확인일은 11-09 KST다. 남자 25위 163.10점, 여자 28위 156.00점. API `decimalPoints` 사용. 직전 스냅샷 기준일이 없으므로 순위 변동은 확인 불가로 표시한다. 현재 랭킹은 2028 최종 선발 랭킹이 아니다. 응답 SHA256과 소스 API는 `rankings-official.json`에 기록했다.

## 보호·남은 범위

- 기존 DB, 선수 ID, 선수 MASTER, 스냅샷, 자동화, 운영 페이지는 수정하지 않았다. 명단 객체는 v1과 동일함을 비교 확인했다.
- 여자 AVC컵·남녀 동아시아 전용 KVL 상세 페이지 3개는 확인되지 않았다. `KVL 상세 준비 중`과 공식 결과 링크를 제공한다.
- 2025/2024 선택은 빈 자료 안내와 기존 히스토리로 연결한다. 미출전으로 해석하지 않는다.
- 여자 히스토리/세대추적 및 일부 프로필·코치/스태프는 기존 구축 범위에 맞춰 안내한다. 여자 아시아선수권 홈 명단 연결은 준비 중 상태를 유지한다.
- 최근 경기/다음 일정은 기존 KVL 경기 스냅샷 기준이다. 다음 개별 경기 미등록 시 일정 미정이다.
- 실시간 랭킹 수집이나 자동 갱신 작업을 추가하지 않았다.
