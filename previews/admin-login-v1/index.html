관리자 인증 로그인 전

GitHub 계정 확인

K-Volley Lab 저장소의 소유자 계정으로 로그인하세요.

토큰은 이 탭에서만 사용하며, 새로고침하거나 로그아웃하면 다시 입력해야 합니다.

처음이라면, 인증 토큰 준비하기
  1. GitHub 토큰 발급 화면 열기 ↗
  2. Resource owner에서 kvolleylab을 선택하세요.
  3. 기간을 7일처럼 짧게 설정하고, 저장소는 kvolleylab/kvolleylab만 선택하세요.
  4. 권한은 기본 Metadata · Read-only만 사용합니다. Contents 쓰기 권한은 필요하지 않습니다.
  5. 생성한 토큰을 위 입력칸에 붙여 넣으세요.

토큰은 비밀번호처럼 다뤄 주세요. 채팅으로 보내지 말고 이 테스트 화면에만 입력하세요.
