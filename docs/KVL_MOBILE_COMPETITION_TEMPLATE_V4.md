# K-Volley Lab 모바일 대회 페이지 기본 템플릿 v4

## 목적

K-Volley Lab 모바일 대회페이지를 **대회 데이터·테마만 바꾸면 동일한 UI로 재사용**할 수 있도록 구조와 세부 시각 규격을 하나의 공통 템플릿으로 고정한다.

이번 v4에서는 현재 가장 완성도가 높은 `AVC 여자 대륙선수권 2026` 모바일 화면의 **시각 수치와 카드 배치**를 1회성 보정 기준으로 사용해 공통 규격을 확정한다.
다만 실제 여자부 페이지 자체는 Source of Truth가 아니다. 앞으로의 Source of Truth는 아래 공통 템플릿 파일들이다.

## Source of Truth

- 규격 문서: `docs/KVL_MOBILE_COMPETITION_TEMPLATE_V4.md`
- 신규 HTML 시작점: `templates/competition-page-v1.html`
- 공통 대회 UI: `assets/css/kvl-competition-template-v1.css`
- 모바일 세부 UI 규격: `assets/css/kvl-mobile-competition-template-v3.css`
- 공통 렌더러: `assets/js/kvl-competition-template-v1.js`
- 데이터 예시: `data/competitions/_template/competition-v1.template.json`

기존 `kvl-mobile-competition-template-v1.css`, `v2.css`는 호환용으로 유지하되 신규·정리 대상 페이지는 v3 세부 UI 규격을 마지막에 로드한다.

## 1. 검수 기준

## 14. 개발 원칙

- 실제 대회 HTML 안에 공통 모바일 숫자값을 추가하지 않는다.
- 두 페이지의 같은 컴포넌트가 다르면 공통 CSS를 수정한다.
- 여자부는 v4 규격을 만들기 위한 1회성 보정 기준일 뿐, 이후 기준은 공통 템플릿 파일이다.
- 신규 MutationObserver로 레이아웃을 패치하지 않는다.
- 데이터/대회규정 차이는 renderer/data에서 처리하고 시각 규격은 공통 CSS에서 처리한다.
- 새 대회는 `templates/competition-page-v1.html`에서 시작한다.
