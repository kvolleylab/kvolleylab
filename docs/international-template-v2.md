## 화면 규칙

1. 기존 KVL 메뉴·내비게이션을 유지한다. 대회 한눈에 / 경기일정·결과 / 순위 / 대진·최종순위 / 참가국·선수명단 / 공식자료의 여섯 기능을 제공하며 명칭은 실제 방식에 맞춘다.
2. 승인된 Hero 원본의 비율·선명도·그라데이션과 실제 텍스트를 보존한다. 제목 PC 최대38px·모바일24px, 부제15/12px, 날짜·장소14/11.5px, 상단 분류11/10px, 상태11/9px. 국내 Hero의 글자 크기도 같으며 국내 색상과 이미지는 유지한다.
3. `meaning`·`qualifications` 원문은 한눈에 기본 정보 아래, 달력 위에 노출한다. 설명과 확정 성과를 구분하고 중요한 내용 전체를 닫힌 펼쳐보기에 넣지 않는다. 설명 내용은 중복 저장하지 않는다.
4. PC 경기행은 시간150px / 가변 대진 / 세트285px를 사용한다. 5세트 공간을 확보하며 보조 설명의 가운데를 전체 세트 스코어의 중심축에 맞춘다. 모바일의 긴 설명만 해당 행에서 스크롤하고 본문 전체는 넘치지 않는다.
5. 팀 로고·이름을 선택하면 전체 경기·승·패·예선 승률·전체 승률 카드를 달력 위에 표시하고, 그 팀의 달력과 전체 경기 목록을 둘 다 펼친다. `structure.teamResults.summary: record`로 공통 성적 카드를 선택하며 `preliminaryStages`로 예선 범위를 지정한다. 승률은 완료 경기만 집계하고 단계 미확인/해당 없음/완료 경기 없음을 구분한다. 달력은 `홈팀 vs 원정팀` 또는 등록 스코어를 사용한 `홈팀 3-1 원정팀`이다. PC 가로/모바일 세로 배치이며 국명을 생략하지 않는다. 날짜 클릭 팝업·팀 선택·선수 연결을 유지한다.
6. 단일리그의 상태/결과가 중복되면 `structure.standings.showStatus: false`로 상태만 생략한다. 조별순위의 조 열, 순위 계산과 결과는 그대로 유지한다.
7. FIVB 남자 보라 #5B3A8E / 연한 배경 #F3EFFA, 일반 점수 #4B5563. 계열색과 여자부 로즈 우선순위는 Theme Policy v1 및 운영원칙 MASTER를 따른다. VNL 달력의 국가명 #142B45, 흰 카드와 파랑 표시선 #5D9EE8, 결과는 계열색을 사용한다. 실제 우승·메달 강조에만 금색을 사용한다.

## VNL에만 해당하는 설정

`data/competitions/vnl-men-2026/config.json`과 `data.json`의 단일 예선·8강 파이널, 참가국·경기·최종순위·선수명단·세계랭킹 설명을 그대로 읽는다. 예선순위는 108개 예선 경기 범위와 기존 18행을 보존한다. 파이널 경기 8개를 더하지 않는다. 표시 어댑터는 중국의 결과 문구를 ‘개최국’으로 표시하고 원본 진출 상태를 바꾸지 않는다. 기존 연한 파랑 파이널 카드·연한 초록 세계랭킹 카드와 설명 전체를 보존한다.

## 다른 대회 적용 절차와 영향

최신 승인된 config/data와 운영 기준을 확인한 뒤 대회별 명칭·계열·성별·상태·단계·순위 방식·진출 규정·설명·공식 근거·국기/로고·명단 링크를 입력 또는 선택한다. 기존 모듈로 처리되는지 먼저 확인한다. VNL 구조를 임의로 복사하지 않는다. 랭킹/다른 대회 진출권은 해당 시즌 근거가 확인된 내용만 표시하며 미확인과 해당 없음은 구분한다.

현재 브랜치의 공유 모듈을 사용하는 격리 미리보기에서 실행 허용/표시 선택만 확장해 1180·390·360 및 관련 탭·팀 경로를 검수한다. 원본 데이터를 바꾸지 않고 문서화한 수정이 필요한 사실은 별도 제안한다. 이후 사용자가 지정한 대회부터 운영 적용한다. 이번 변경으로 AVC·VNL·국내 운영 화면을 교체하거나 다른 대회 config를 일괄 수정하지 않는다.
