# K-Volley Lab 기존 대회 디자인 관리자 v2 — 편집 시안

**개발 목적:** 새 대회 생성기가 아니라 **이미 생성·운영 중인 대회의 데이터가 채워진 상태에서** 서식을 조정하는 관리자 화면. 원본 경기·선수·순위·MASTER 데이터는 읽기 전용입니다.

- 상태: `PROTOTYPE / LOCAL READ-ONLY EDITOR / NOT DEPLOYED`
- 기준: 2026-11-11, KVL GitHub `main` (분기 생성 시 최신 SHA 기록)
- 상위 기준: `AGENTS.md`, `PROJECT_RULES.md`, `DESIGN_SYSTEM.md`, `docs/KVL_DECISION_LOG.md`, Google Drive 운영원칙 MASTER v19
- 이전 `KVL Template Manager v1`의 '새 대회 입력' 흐름을 **요구사항 변경으로 대체**합니다. 신규 대회 생성·CSV 입력·대회 데이터 편집은 이 도구의 주 기능이 아닙니다.

## 현재 가능한 기능

1. **기존 대회 선택:** GitHub 공개 `main` tree의 `data/competitions/*/config.json` 목록을 읽고 대회를 선택하면 `config.json`과 `data.json`을 읽음. 자동 조회 불가 시 특정 slug 직접 입력 또는 두 JSON 로컬 가져오기 가능.
2. **실제 데이터 포함 미리보기:** 대회명·시즌·상태·참가팀/국가·로고·경기 일부·순위 일부를 표시. 실제 대회 값이 사용됨. **미리보기 DOM은 별도로 만든 축약 버전이므로 운영 화면과 픽셀 동일하다는 뜻은 아님.**
3. **글씨 편집:** 이름 표시 방식(전체 줄바꿈/2줄 제한/한 줄 축소/말줄임), 팀명 크기 변경. 너무 긴 이름을 1줄에 전부 표시할 공간이 없다면 글자 크기·카드 폭을 별도로 조정해야 함.
4. **로고 편집:** 크기/좌우·상하 이동/이름과 간격을 한 번에 변경.
5. **순위표 편집:** 승/패 열 너비, 숫자 좌우·상하 이동, 글씨 크기, 행 상하 간격 변경. 승·패·승점 **값 자체를 변경하지 않음**.
6. **HERO 미리보기:** 기존 이미지 참조 및 PC용 위치/맞춤/제목 크기/색상. 사용자가 고른 사진은 로컬 미리보기 전용. 자동 게시·서버 업로드 아님.
7. **적용 범위 분리:** 전체 공통 → 국내·국제·프로 계열 공통 → 개별 대회 순서로 디자인 설정을 합침. 서로 다른 종류의 대회에 덮어쓰지 않고 필요한 범위만 조정.
8. **취소/초기화/내보내기:** 마지막 디자인 수정 되돌리기, 범위별 설정 초기화, 디자인 JSON 다운로드·다시 가져오기. 저장 파일은 `KVL_Visual_Overrides_v2.json`이며 대회 점수·선수·MASTER 자료는 포함하지 않음.

## 사용법

- 압축을 해제해 `KVL_Existing_Competition_Editor_v2.html` 파일을 Edge/Chrome으로 엽니다. 네트워크 연결 필요.
- 대회 목록이 뜨면 기존 대회를 선택합니다. 예: `university-goseong-men-2026` 또는 `vnl-men-2026`.
- **수정 적용 범위**를 선택합니다. 예: 한 대회만 / 국내 공통 / 국제 공통 / 프로 공통 / 전체 공통.
- '팀명·로고', '순위표', 'HERO' 탭에서 값을 조정하며 PC/모바일을 비교합니다.
- '저장·복원'에서 JSON으로 내보냅니다. **이 저장은 사용자의 PC에만 저장**되며 운영 홈페이지에는 반영되지 않습니다.
- 자동 자료 로딩이 차단되면 사용하려는 대회의 GitHub `data/competitions/<slug>/config.json` 및 `data.json`을 받아 '두 파일 열기'에서 불러옵니다.

## 중요 경계

- **읽기 전용 데이터:** 대회·참가팀·선수·경기·순위의 출처와 ID를 재작성하지 않음. 자동 갱신 중인 V-리그·KOVO컵 MASTER/Worker/Actions와 분리.
- **관리자 로그인이 아직 없음:** 이 버전은 독립 HTML 시안. 사용자 인증·서버 저장·발행 기능 없음.
- **실제 CSS/마크업 다를 수 있음:** DOM 내 `.dv2-team-tile`, `.dv2-standings-table`, `.kvl1180-inline-logo` 등 실제 공통 컴포넌트의 CSS 우선순위, 반응형 분기, 팀명 줄바꿈 보호 정책을 검토해야 함. 적용 전 동일 대회 및 다른 대회의 PC 1180 / 모바일 390·360 검수 필수.
- **업로드 이미지:** 선택한 이미지는 로컬 object URL로만 미리보기. 새 WebP 파일 생성·서버 업로드·공식 사용권 확인 별도.
- **민감정보/보안:** 편집기는 공개 GitHub의 JSON만 읽고 인증 토큰·개인 메모·비공개 데이터는 요청하지 않음. 임의 CSS/JS 입력·실행을 허용하지 않는 제한된 디자인 토큰 계약.
- **본 PR은 feature 브랜치의 신규 파일만 포함**하며 운영 `main`, 공개 DB, Supabase, Pages, 경기/선수 자동화, Cloudflare Worker를 수정하지 않음.

## 이후 개발 (검수 후)

**2차:** Supabase 서버측 관리자 로그인(RLS/Edge Functions), 기존 대회 목록과 실제 운영 DOM의 동일 출처 미리보기, PC/모바일 분리 속성, 편집 설정 드래프트 저장/이력, 디자인 속성별 명시적 적용 범위.

**3차:** CSS 공통 렌더러에 토큰만 반영, 변경 전/후 스냅샷 및 영향 대회 리스트, 공통 수정 시 선택된 대회들에 대한 일괄 회귀 테스트, 사용자 승인 후 GitHub PR/Pages 배포 및 안전한 롤백.

특히 순위표의 `승·패`는 경기 데이터 필드가 아닌 **표의 렌더링 위치만** 수정해야 합니다. 공통 변경은 팀 로고·점수 집계·선수 ID·대회별 순위 규정에 간섭하지 않도록 제한합니다.
