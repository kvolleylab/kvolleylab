# K-Volley Lab 모바일 대회 페이지 기본 템플릿 v1

기준 화면: 모바일 390px. 최초 기준 페이지는 `international-competition-avc-women-continental-2026.html`.

## 1. 상단 메뉴
- 6개 고정: `한눈에보기 / 경기일정 / 조별순위 / 최종순위 / 참가국 / 공식자료`.
- 모바일에서는 1행 4개(`한눈에보기`~`최종순위`) + 2행 2개(`참가국 / 공식자료`).
- 가로 스크롤 금지.

## 2. 한눈에 보기 KPI 카드
- 참가국 → 참가국 페이지.
- 조별리그 → 조별순위 페이지.
- 전체 경기 → 경기일정 페이지.
- 8강 진출 → 최종순위 내 8강 토너먼트 위치.
- 2×2 카드 배치를 기본으로 사용.

## 3. 대회 월간 달력
- 해당 대회가 속한 월을 7열 달력 한 화면에 표시.
- 가로 스크롤 금지.
- 경기 있는 날짜는 경기 수를 표시하고 클릭 가능.
- 날짜 클릭 시 경기일정 페이지를 유지한 채 해당 날짜 경기 묶음으로 이동.
- 다른 날짜 경기 묶음도 그대로 유지.

## 4. 경기일정 카드
모바일 정보 순서:
1. 경기시간
2. 양 팀 국기 + 국가명 + 세트스코어
3. 세트별 스코어
4. `단계 · 조 · 경기장/현지시간` 보조정보

- 양 팀 국기는 중앙 스코어를 기준으로 같은 열에 대칭 정렬.
- 국기 크기는 동일.

## 5. 최종순위
- 1~4위 카드를 모바일 한 줄 4개로 표시.
- 국기 이미지 비율과 크기를 4개 모두 동일하게 유지.
- 카드 내부 여백은 최소화.
- 1위에는 `LA올림픽 직행`을 텍스트로 표시할 수 있음.
- 최종순위 아래에 8강부터의 결선 토너먼트를 연결.

## 6. 참가국
- 모바일 2열 카드 배치를 기본으로 사용.
- 국기 / 한글 국가명 / 영문명 / 조 표기.

## 재사용 파일
- 공통 모바일 CSS: `assets/css/kvl-mobile-competition-template-v1.css`
- 기준 구현 페이지: `international-competition-avc-women-continental-2026.html`

향후 새 대회 모바일 페이지는 특별한 사유가 없는 한 이 구조를 기본값으로 사용한다.
