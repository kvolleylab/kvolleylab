# 대학대회 공통 템플릿 v1

## 목적

고성대회에서 완성한 화면 구조를 모든 대학대회에 재사용한다. 새 대회는 별도 디자인 작업 없이 대회 JSON과 대회 목록 항목을 추가하는 방식으로 운영한다.

## 신규 대회 추가 순서

1. `data/competitions/_university-template.json`을 복사한다.
2. 파일명을 대회 ID로 저장한다. 예: `data/competitions/jongbyeol-2026.json`
3. 대회명, 기간, 장소, 경기, 최종 순위, 공식자료를 입력한다.
4. `data/competitions/university-index.json`에 대회를 등록한다.
5. 남녀부별 제공 기능과 선수 DB 연결 여부를 표시한다.
6. 경기 ID 중복, 경기 수, 스코어, 최종 순위를 검수한다.

## 필수 데이터

- `competitionId`
- `name`
- `shortName`
- `dates.start`, `dates.end`
- `location`
- `venues`
- `updatedAt`
- `games`
- `sources`

## 경기 데이터 규칙

- 날짜: `YYYY-MM-DD`
- 시간: `HH:MM`
- 부문: `남대부` 또는 `여대부`
- 단계: `예선`, `6강`, `준결승`, `결승`
- 예선 조가 없으면 `pool`은 `null`
- 경기 스코어: `3-0`, `3-1`, `3-2` 형식
- 세트 스코어: `25-20` 형식의 배열
- 모든 시간은 한국시간(KST) 기준

## 결선 구조

- `six-team`: 남대부 6강·준결승·결승 구조
- `semifinal`: 준결승·결승 구조
- `final-only`: 결승만 존재하는 구조
- `league`: 별도 결선 없이 리그 순위로 종료

## 선수 DB 연결

선수 DB가 연결된 부문은 참가대학 카드에서 선수 수와 팀 상세페이지를 제공한다. 연결되지 않은 부문은 경기 데이터에서 참가팀을 생성하고 `선수명단 자료 미연결`로 표시한다.

## 검수 기준

- 대회 전체 경기 수와 JSON 경기 수 일치
- 남녀부 경기 수 일치
- 경기 승자와 최종 순위 일치
- 준결승·결승 진출 흐름 일치
- 같은 팀의 명칭 통일
- 공식자료 링크 확인
- PC·모바일 화면 확인
