# K-Volley Lab 대회 페이지 검수 체크리스트

모든 신규 대회 페이지와 대회 페이지 수정 작업은 아래 항목을 확인한 뒤 공개한다.

## 1. 상단 영역
- [ ] 대회명과 연도가 정확하다.
- [ ] 메인 제목은 짙은 배경 위 흰색으로 표시된다.
- [ ] 대회 기간, 개최지, 상태가 정확하다.
- [ ] 메뉴 순서가 `한눈에 보기 → 경기결과 → 조별 순위(해당 시) → 최종 순위 → 참가학교/참가대학 → 공식자료`로 통일되어 있다.
- [ ] 모든 메뉴 주소에서 동일한 레이아웃이 유지된다.

## 2. 한눈에 보기
- [ ] 전체 경기 수가 원본 자료와 일치한다.
- [ ] 참가 부문과 참가팀 수가 일치한다.
- [ ] 월간 달력이 표시된다.
- [ ] 날짜별 경기 수와 대회 단계가 표시된다.
- [ ] 남녀부 또는 부문 전환이 필요한 대회는 전환 기능이 작동한다.

## 3. 경기결과
- [ ] 원본 자료의 전체 경기가 누락 없이 등록되어 있다.
- [ ] 날짜, 경기장, 시간, 부문, 단계가 정확하다.
- [ ] 최종 스코어가 정확하다.
- [ ] 세트별 스코어가 정확하다.
- [ ] 최종 스코어와 세트별 승패 수가 일치한다.
- [ ] 승리팀이 강조 표시된다.
- [ ] 양 팀 로고 또는 공식 로고 교체 전 임시 마크가 표시된다.
- [ ] 부문별·단계별 필터가 작동한다.

## 4. 순위와 토너먼트
- [ ] 우승, 준우승, 공동 3위가 공식 결과와 일치한다.
- [ ] 사다리형 결선 토너먼트가 표시된다.
- [ ] 8강/6강, 준결승, 결승 대진이 공식 결과와 일치한다.
- [ ] 토너먼트 경기 스코어가 경기결과 메뉴와 일치한다.
- [ ] 조별 순위가 있는 대회는 순위 결정 기준과 결과가 정확하다.

## 5. 참가팀
- [ ] 부문별 참가학교/참가대학 수가 정확하다.
- [ ] 팀명이 공식 명칭으로 통일되어 있다.
- [ ] 공식 로고가 있으면 사용한다.
- [ ] 공식 로고가 없으면 임시 마크임을 구분하고 추후 교체 대상으로 기록한다.

## 6. 공식자료와 대회요강
- [ ] 대회요강 전용 공간이 있다.
- [ ] 공식 대진표, 경기스코어, 결과표 링크가 연결되어 있다.
- [ ] 링크가 새 창에서 정상적으로 열린다.
- [ ] 최종 업데이트 날짜가 표시된다.
- [ ] 원본 자료의 오류나 불일치가 있으면 화면에 안내한다.

## 7. 배포 전 회귀검사
- [ ] 기존 대회 페이지의 경기결과와 세트스코어가 유지된다.
- [ ] 기존 대회의 최종 순위와 토너먼트가 유지된다.
- [ ] PC와 모바일에서 메뉴가 잘리지 않는다.
- [ ] 모든 메뉴를 각각 눌러 동일한 정렬과 디자인을 확인한다.
- [ ] 캐시 버전을 갱신했다.
- [ ] 실제 공개 주소에서 최종 확인 후 완료 처리한다.
