# 올림픽·대표팀 로드맵 공통 홈페이지 연결 보정 v1

2026-11-17 KST · IMPLEMENTED / LOCAL QA PASSED / RELEASE AUTHORIZED

## 확인한 문제

사용자가 운영 연결 후 “홈페이지와 자연스럽게 연결된게 아닌데 확인해봐”라고 지적했다. 실제 대표팀 홈의 공통 왼쪽 메뉴·로그인·모바일 브랜드 바가 로드맵 이동 시 별도 가로 메뉴로 바뀌었다. 링크가 열린다는 사실만으로 홈페이지 통합을 완료했다고 판단한 것이 원인이다. PR #341의 데이터·로드맵 구현을 유지하면서 외부 페이지 틀과 진입 동선을 보정한다.

Base main: `196d72ea3727c5f0515462f2a0f048b3fba68bd5` (PR #344 포함). 기존 운영 연결 승인 및 그 결과에 대한 수정 요청 범위로 진행한다.

## 변경 범위

- `olympic-roadmap.html`, `national-team-history-verification.html`: 기존 `unified-nav.js`를 사용한다. 별도의 프로토타입 헤더는 제거한다.
- `assets/css/olympic-roadmap-site-v1.css`: 대표팀 홈과 같은 1180px 외부 틀 및 PC 20px/모바일 12px 여백을 적용한다. 상단 요약과 하단 타임라인의 양끝을 맞춘다. 기존 로드맵의 글꼴은 전역 글꼴 강제 규칙으로 바뀌지 않도록 한정한다.
- `assets/js/kvl-global-sidebar-v1.js`: 국가대표팀 하위 메뉴에 `올림픽·대표팀 로드맵`을 추가하고 로드맵/검증 페이지의 현재 위치를 표시한다. 기존 메뉴·로그인·모바일 동작을 재사용한다.
- `assets/js/unified-nav.js`: 공통 메뉴 스크립트의 캐시 버전만 변경한다.
- `national-team.html`, `assets/js/national-team-home-v2.js`: 남자대표팀 상단 LA28 현황을 전체 로드맵에 직접 연결한다. 하단 전체보기 및 여자부의 기존 경로는 유지한다.

역사 JSON, 올림픽 주기 JSON, 원본 타임라인 CSS·렌더러·모델, MASTER, 경기·선수 DB, 로그인 권한, 자동화, 기존 LA28 페이지는 변경하지 않는다. 이번 변경에는 대회 결과 재조사가 필요하지 않으므로 기존 검증 날짜·미확인 목록을 그대로 유지한다. Drive 원장 수정은 없다.
