# 통합달력 막대 분리·중앙 정렬·종료 표현 v6

Status: PROTOTYPE VERIFIED / OPERATING SITE NOT DEPLOYED.

사용자 최신 요청에 따라 50% 겹침을 없애고 글자를 막대의 세로 중앙에 정렬한다. 종료된 대회는 운영 통합달력과 같은 정도로 막대와 말풍선을 흐리게 표시한다. 기존 달력 디자인·3열 12개월 배치·요일·색상 체계·대회명 뒤 장소·필터·이동·데이터 연결을 보존한다.

## 기준과 변경 범위

- 최신 확인 main: `f560f3b0473eca5e3933461f13b725ed4a9cdb32`. 작업 전 시안 HEAD: `4b1a41fbcdedf97a18aa9f1f5cc183bdc4fd4dce`. 기존 Draft PR #243에서만 작업한다.
- 실제 운영 `https://kvolleylab.com/competition-calendar.html?year=2026`의 종료 막대 computed opacity `.62`, 높이 `16px` 및 말풍선 배경 `rgb(16,35,63)`를 확인했다. 운영 말풍선 자체 opacity는 1이나 종료 막대 내부에 있어 부모의 `.62`가 함께 적용된다.
- 시안 연간 막대 16px / 행 간격 18px, PC 월간 26px / 30px, 모바일 월간 24px / 28px. 막대끼리 2~4px 간격을 둔다. 주별 기존 행 계산식에 전체 막대 높이를 반영해 날짜 아래 공간을 확보한다.
- 최신 ‘겹치지 않게’ 요청을 위해 일정이 많은 주의 높이는 필요한 만큼 증가한다. 과거의 정확한 카드 높이 일치 및 50% 겹침·하단 노출 영역 글자 배치 결정을 이 범위에서 대체한다. 대회를 숨기거나 삭제하지 않는다.
- 텍스트와 남녀 배지는 세로 중앙에 배치한다. 기존 색상, 옅은 배경, 테두리, 말줄임, 전체 제목 `(장소)` Tooltip과 링크를 유지한다.
- 종료 상태는 기존 Asia/Seoul 날짜 판정에 따른다. 종료일까지는 진행 상태이고 그 다음 날부터 종료 상태다. 페이지를 읽을 때의 날짜를 사용하며 별도 자정 자동 새로고침 타이머는 추가하지 않았다.
- 종료 막대 opacity `.62`. 별도 고정 위치 Tooltip에도 `.62`와 운영 배경색을 직접 적용한다. 진행/예정 Tooltip으로 전환할 때 종료 클래스를 제거한다. 글자에 blur 필터를 넣지 않는다.
- 운영 HTML/CSS/JS, 공통 UI, MASTER, ID, 기간/성별/장소 데이터 및 원본 대회 링크는 변경하지 않는다.
