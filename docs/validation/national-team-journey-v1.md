# 대표팀 연간 기록과 올림픽 경로 통합 v1

검증일: 2026-11-23 (KST). Base main: `31bf24e7968c4ca4137b33617efe9f3089c4cd02`.

사용자는 매년 대한민국 성인 남자대표팀 참가 대회를 같은 타임라인에 누적하고 올림픽 출전 경로만 필터로 볼 수 있도록 하는 제안에 “그렇게 진행해봐”로 실행을 승인했다. 기존 운영 페이지의 후속 수정이며 별도 대회·올림픽 페이지를 만들지 않는다.

## 최종 동작

- 하단 제목: `대한민국 남자대표팀 로드맵`. 부제: `연도별 참가 대회와 올림픽 도전 기록`.
- 일반 진입의 기본 선택은 `전체 기록`. 기존 `핵심 대회`, `진출 실패`와 함께 `올림픽` 필터의 표시명을 `올림픽 출전 경로`로 명확히 한다.
- 기존 필터 값 `filter=olympic`과 대회 `event` 링크를 유지한다. 이전 북마크를 바꾸지 않는다.
- 상단 LA28 배정 1/5/3/3 및 개최국·대륙선수권·월드컵·세계랭킹 펼침은 별도 모듈 그대로 유지한다.
- 긴 한글 제목과 필터가 잘리지 않도록 페이지 범위 CSS를 추가한다. 모바일에서는 필터 전체 폭을 사용하고 현재 연도 버튼은 아래 오른쪽에 배치한다. 카드 행과 상세 정보 글씨 크기는 보존한다.

## 기록 및 분류

이번 변경은 62개 기존 검증 기록을 새 구조에서 재사용한다. 새 역사 결과를 조사·추가한 배치는 아니다. 주요 기록 선별 수록이라는 기존 안내와 미확인 항목을 유지하며 전체 연도의 모든 참가 대회가 수록된 것으로 주장하지 않는다.

| 2026 기록 | 전체 기록 | 올림픽 출전 경로 |
| --- | --- | --- |
| AVC 남자컵 | 표시 | 제외 |
| 남자 동아시아선수권 | 표시 | 제외 |
| AVC 남자 아시아선수권 | 표시 | 표시 |
| 아이치·나고야 아시안게임 | 표시 | 제외 |

기존 모델은 올림픽 본선·예선 분류 또는 명시적인 올림픽 출전권 `qualificationOutcomes.target`을 기준으로 경로 필터를 구성한다. 일반 대회의 순위·랭킹 영향만으로 올림픽 경로를 추정하지 않는다. 본선 미출전과 실제 예선 탈락, 다음 대회 참가권과 올림픽 출전권은 기존 독립 필드를 보존한다. 아시아선수권의 월드컵 진출 확정 및 LA28 아시아 직행권 미획득도 그대로 남는다.

향후 연간 대회는 같은 역사 데이터에 검증한 참가/일정/결과/출처를 추가한다. 올림픽 관문이면 관계를 함께 기록하며 별도의 중복 대회 레코드를 만들지 않는다. 공식 경기정보 없이 대회 개최만으로 대한민국 참가를 만들지 않는다. 등록 절차와 공개 검토 해시는 기존 운영 기준을 따른다.
