## 사용자 승인과 변경 범위

사용자가 “운영반영해”로 기존 월드컵 개선분 반영을 승인하고, “개최국 1장”도 외부 사이트 이동 대신 홈페이지 안에서 간단한 개최 정보를 표시하도록 요청했다.

- 승인된 월드컵 간편 보기와 기존 `fivb-world-cup-2027.html` 개선분을 그대로 통합한다. [11월 18일 자료 검증·프로토타입 보고](world-cup-roadmap-v1.md).
- 개최국 카드를 버튼으로 바꿔 같은 요약 안에 미국·로스앤젤레스 정보가 펼쳐지도록 했다. 미국 남녀 자동 출전, 남녀 각각 1장 및 각각 총 12장에 포함됨을 명시한다.
- 실내배구 경기장 혼다 센터(애너하임), 배구 경기 기간 2028.07.15–07.30, 올림픽 개·폐막 2028.07.14–07.30을 구분한다. 날짜는 현지 기준이며 변경 가능 안내를 둔다.
- LA의 1932·1984년에 이은 세 번째 하계올림픽 개최와 공식 출처를 간단하게 표시한다.
- 개최국 정보는 LA2028 주기 JSON의 `hostOverview`에 저장하며 공식 검증·동일 주기·출처가 있어야 표시한다. 2032에 LA 자료를 복사해도 표시하지 않는다.

## 보존과 검증

- Node 테스트 **38/38 통과**: 기존 25 + 월드컵 9 + 개최국 4.
- 실제 Chromium PC와 390px·360px 너비 iframe으로 모바일 레이아웃 확인. 모바일 실기기 검증은 아니다. 개최국 정보의 외부 이동 없음, 펼침/접기·키보드 Escape, 두 너비의 가로 넘침 없음 확인.
- 월드컵 남녀 전환·여자 상세 연결, 대륙선수권 5개 연결, 전체 62 / 진출 실패 17, 2026 연도 접기·펼치기 확인.
- 2032: 공식 출전 규정 발표 전 / 배정 카드 0 / 개최국·월드컵 패널 0 / 역사 62 유지.
- 역사 JSON, 역사 CSS·JS·모델, 대륙선수권 JSON·모듈, 공통 내비게이션은 기존 main 바이트를 보존한다. `olympic-roadmap.html`의 역사 `<main>`도 그대로다.
- 공개 JSON 검수 manifest는 이번 두 JSON의 정확한 SHA-256과 출처로 갱신한다. 미확정 경기 결과·참가 명단을 검증 완료로 승격시키는 의미가 아니다.

## 한계·운영

- 월드컵 최종 순위·우승국·올림픽 획득국은 결과 미확정 상태다. 경기별 상세 일정·최종 엔트리·남자 조 추첨 결과는 이번 반영 범위에 없다.
- 기존 Drive 출전권 MASTER는 2026-07-25 구 명칭·한국 참가 상태가 남아 있음을 다시 읽기 확인했다. 이 작업에서 Drive를 수정·동기화하거나 자동 수집을 활성화하지 않는다.
- 기존 LA28 주소·북마크를 유지한다. 과거 올림픽 보관/2032 전환의 관리자 검증 정책도 유지한다.
- 테스트용 iframe·리디렉트 index·로컬 미리보기 설정은 운영에 포함하지 않는다.
- 복구는 이 PR의 범위만 revert한다. 다른 운영 변경을 과거 main으로 되돌리지 않는다.
