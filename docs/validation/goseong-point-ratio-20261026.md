Status: APPROVED / IMPLEMENTED / VERIFIED. Merge, Pages and live verification are recorded in the release PR.

## 문제와 수정

고성대회 남녀 data.json의 조별순위 22행은 세트별 점수가 모두 있는데도 pointRatio가 `-`로 저장되어 있었다. 공통 렌더러는 이 사전 계산 값을 그대로 표시하므로 발생한 누락이다.

- 기존 예선 39경기(남30/여9)의 **총득점 ÷ 총실점**으로 22팀 점수득실률을 재생성한다. 본선 8경기는 제외한다.
- 재생성기는 기존 KVLTournamentEngine을 재사용하며 `wins → pointRatio → setRatio → headToHead`를 명시한다. 원시 비율로 순위를 비교하고 출력만 소수 셋째 자리로 반올림한다. 승점은 정렬에 사용하지 않는다.
- 완성된 예선 일정, 조 소속, 세트 수·승리 세트·점수 완전성을 검사하고 불완전/충돌 기록이면 생성을 중단한다.
- 현재 각 조의 승수가 모두 달라 기존 순위·진출팀·승패·승점·세트비율은 그대로다. 두 JSON의 변경은 pointRatio 22개뿐이다. 47경기, 참가대학·팀 ID·최종순위·결선·선수 경로는 동일하다.
- 성균관대 291/240의 정확한 반올림은 1.213이다. JS의 `(291/240).toFixed(3)`가 1.212가 되는 부동소수점 표시 문제를 예선 종합순위의 점수 비율 한 줄에서 수정해 조별/PC 종합/모바일 종합 표시를 일치시킨다.
- 다른 대회의 정렬 정책과 별도의 KVL 예선 종합순위 기준(승률 → 세트비율 → 점수비율)은 변경하지 않는다.
