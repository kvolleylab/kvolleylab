## 표시 계약

기존 공통 domestic-home 모듈의 세 번째 카드만 교체한다. 참가팀·등록 경기·장소 카드와 전체 카드 수는 유지한다. 기존 `href('groups')`를 재사용해 원래 예선 조편성/정규리그 순위 페이지로 이동한다. 새 엔진이나 별도 순위 데이터를 만들지 않는다.

| 유형 | 제목 | 본문 | 이동 문구 |
|---|---|---|---|
| 대학 조별 예선 | 예선 조별 현황 | 각 조의 기존 rank 1 대학 | 조편성·순위 보기 |
| 대학 단일 예선 | 예선 순위 | 예선 1위 대학 | 예선 순위 보기 |
| V리그 | 정규리그 순위 | 현재 1위 팀·원본 승점 | 전체 순위 보기 |

각 조를 빠짐없이 표시하며 A/B만 하드코딩하지 않는다. 종료한 대학 예선에는 `예선 최종 순위`, 단일 예선은 `예선 최종 1위`를 사용한다. V리그는 명시적 `regularSeasonComplete`와 정규리그 필수 경기 완료가 일치해야 `정규리그 1위`로 바뀐다. 예선/정규리그 1위를 대회 우승으로 표현하지 않는다.

시작 전에는 확인된 조별 팀 수 또는 `개막 전`/`예선 시작 전`을 표시한다. 첫 경기가 진행 중인데 완료 결과가 없으면 개막 전으로 표시하지 않는다. 순위를 안전하게 요약할 수 없으면 `순위 확인 중`과 기존 이동 링크를 제공한다.

모바일의 2열 카드·기존 아이콘·테마를 유지하고 새 카드 안에서만 팀명과 접두어의 줄바꿈을 허용한다. PC 팀명 15px, 모바일 13px. 긴 팀명은 잘라 감추지 않는다. 키보드의 기존 링크·Space 동작을 유지하며 링크를 중첩하지 않는다.

## 데이터 사용과 신뢰 확인

`selectOverviewStanding(d, now)`는 기존 정규화된 순위 행의 `rank === 1`만 읽는다. 배열 첫 행·최고 승점으로 선두를 새로 정하지 않는다. 입력 데이터는 수정하지 않는다.

- 대학은 `stage === '예선'` 경기만 대조한다. 남자 U리그의 후속 6강리그와 결선을 제외한다. 여자 U리그는 `standings.rows`를 사용하며 서로 다른 pool 문자열을 억지로 맞추지 않는다.
- V리그는 1~6라운드만 대조한다. 포스트시즌과 시즌 전체 우승 결과는 정규리그 카드에 섞지 않는다.
- 참가팀·순위 행의 코드 연결, 중복, 조별 `matchCount`가 있는 경우 등록 경기 수, 최종 세트승패, 과거 KST 날짜의 누락 결과, 팀별 완료 경기 수와 `games` 또는 `wins+losses` 일치를 확인한다.
- V리그는 기존 게시 파이프라인의 `KOVO_PUBLIC_STAT_API`, `standingsSource`, `completedMatches` 근거도 확인한다. `regularSeasonOnly:false`는 수집 범위이며 순위 단계가 바뀐다는 뜻으로 사용하지 않는다.
- 명시적 미검증 결과, 유효하지 않은 점수, 누락/복수 rank 1 등은 확인 중으로 표시한다. 미출전 팀의 rank:null, games:0 자체는 오류가 아니다.
- 최종 세트승패가 확인된 경기의 개별 세트 득점 `sets:[]`는 허용한다. 여자 U리그의 정상 예선 1위를 이 이유로 숨기지 않는다.
- 연기 경기는 현재순위 대조에서 제외할 수 있지만 예선 종료 판정에는 미완료로 남긴다.
- `updatedAt`은 마지막 내용 변경 시각이므로 임의의 24/48시간 TTL로 정상 휴식일의 순위를 숨기지 않는다.

이 검수는 기존 게시 데이터와 기존 공식 검증 경로를 재사용한 것이며, 외부 경기 결과를 새로 수집하거나 Google 경기 MASTER를 다시 써서 갱신한 작업이 아니다.
