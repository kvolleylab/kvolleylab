## 3. 공식 일정과 경기 방식

### 공식 일정

아래는 운영요강 제16조의 남녀 구분 일정이다. 대회개요의 전체 기간과 일치한다.
기간의 마지막 날짜는 시리즈가 최대로 진행될 때의 예정 범위이며, 모든 차전이
반드시 개최된다는 뜻은 아니다.

| 단계 | 남자부 | 여자부 | 근거 |
|---|---|---|---|
| 정규리그 | 2026-10-31 ~ 2027-04-02 | 2026-10-31 ~ 2027-04-02 | 제16조 ① |
| 준플레이오프 | 2027-04-06 | 2027-04-05 | 제16조 ② |
| 플레이오프 | 2027-04-08 ~ 2027-04-12 | 2027-04-07 ~ 2027-04-11 | 제16조 ③ |
| 챔피언결정전 | 2027-04-14 ~ **2027-04-22** | 2027-04-13 ~ **2027-04-21** | 제16조 ④ |

대회개요의 남녀 통합 범위는 준PO 4/5~6, PO 4/7~12, 챔피언결정전 4/13~22다.
정규리그는 각 126경기, 총 252경기이며, 포스트시즌을 포함한 시즌 총 경기 수는
공식 개요에서 **262~270경기**로 제시한다. 조건부 준PO와 조기 시리즈 종료 때문에
전체 경기를 고정 270경기로 간주하면 안 된다.

### 진출·시리즈·홈경기 조건

- **준플레이오프:** 최종 정규리그 3·4위의 승점 차가 3점 이내일 때 조건부 단판.
  개최 장소는 정규리그 3위 팀 홈이다. 승점 차가 4점 이상이면 준PO가 열리지 않는다.
- **플레이오프:** 정규리그 2위와 준PO 승자, 준PO 미개최 시 정규리그 3위가 대결한다.
  3전 2선승이며 1·3차전은 정규리그 2위 홈, 2차전은 상대 팀 홈이다.
- **챔피언결정전:** 정규리그 1위와 PO 승자가 대결한다. 5전 3선승이며
  1·2·5차전은 정규리그 1위 홈, 3·4차전은 PO 승자 홈이다.
- **시작 시각:** 제19조 ④에 따라 준PO·PO·챔피언결정전의 경기 시작 시각은
  KOVO와 주관방송사가 협의해 결정한다. 정규리그의 평일/주말 시각을 복사해
  미래 포스트시즌의 확정 시각으로 기록하지 않는다.

대회개요의 PO 2차전 표기는 준PO 승자 홈이며, 운영요강 제18조의 3위 홈 표기는
준PO 승패에 따라 상대가 달라지는 대진 구조와 함께 읽는다. 자동화는 이 명칭으로
참가 팀을 추정하지 않고 공식 확정 대진을 수집한다.
최종 정규리그 순위가 확정되기 전의 순위로 참가 팀을 미리 확정하지 않는다.
2승 또는 3승으로 시리즈가 끝난 뒤 남은 차전은 패배·0:0 종료 경기로 생성하지 않는다.

## 4. 실제 공식 API와 기존 MASTER 대조

### 공식 API 코드와 현재 관측값

[현재 KOVO 공개 웹앱 스크립트](https://kovo.co.kr/assets/index-D20G7jIw.js)의
`leagueNames` 및 `extraLeagues`에서 다음 코드 연결을 직접 확인했다.

| 단계 | leagueCode / gpart |
|---|---|
| 정규리그 | 201 |
| 준플레이오프 | 204 |
| 플레이오프 | 202 |
| 챔피언결정전 | 203 |

기존 공개 `/stat/game-schedule` 경로에 `gcode=001`, `seasonCode=023`,
성별 `gender=1` 또는 `2`, 해당 `leagueCode`, `page=0`, `size=200`으로 조회했다.
남녀 × 3단계의 **현재 시즌 포스트시즌 6개 응답이 모두 정상 응답이며
`totalElements=0`, `totalPages=0`**였다.
이는 이미 공표된 포스트시즌 기간이 없다는 의미가 아니라, 현재 경기별 API에는
미래 포스트시즌의 개별 대진이 아직 올라오지 않았다는 관측이다.
비어 있는 응답을 취소·대회 종료·확정 탈락으로 해석하지 않는다.

실제 응답 형태를 대조하기 위해 이전 `seasonCode=022`의 **남자부만** 추가로 읽었다.
준PO 1경기, PO 2경기, 챔피언결정전 5경기를 확인했다.
PO는 2연승으로 종료되어 실제 응답이 2경기인 사례다.
모든 행에서 `round=1`이었고 `roundName`에 단계명과 1차전·2차전 등의 구분이 있었다.
`gnum`은 예를 들어 남자 준PO 254, PO 256·258, 챔피언결정전 262·264·266·268·270처럼
전체 일정의 번호였다. `round` 또는 `gnum` 자체를 시리즈 차전으로 오인하지 않는다.
이전 시즌 여자부의 전체 경로나 연기·취소 플래그까지 검증했다는 주장은 하지 않는다.

## 5. 운영 종료 경계와 실제 대회 종료의 구분

공식 남녀 전체 시즌의 마지막 가능 편성일은 **2027-04-22**다.
기존 운영 정책의 최종 대조 기간 7일을 유지하면 대조 날짜는 4/23~4/29이며,
운영 갱신의 종료 경계는 **2027-04-30 00:00 KST 미포함**으로 정한다.
이 운영 종료일은 KOVO의 공식 경기 종료일을 4/29로 바꾸는 설정이 아니다.

자동화의 지원 범위는 `season_through_championship`으로 확인하고, 기존
Competition_ID·정규리그 MatchID·공개 경로를 보존한다. 준PO 미개최, PO/챔피언결정전
조기 종료, 아직 미편성인 공식 응답을 구분해야 한다.
정규리그 순위 계산에는 포스트시즌 결과를 섞지 않는다.
향후 공식 일정 변경이 운영 종료 구간을 벗어나면 근거를 확인하여 정책을 개정하며,
날짜만 늘려 미확인 데이터를 확정하지 않는다.

갱신 경계에 도달해도 자동으로 우승이나 기록 보관 완료를 선언하지 않는다.
챔피언결정전의 유효한 3승·진출 경로·공식 최종 확인·MASTER 재조회·실제 공개 게시와
파일 해시까지 맞아야 최종 보관 대상으로 인정한다. 결과가 부족하면 기존처럼
`STOPPED_PENDING_ARCHIVE`로 남긴다.

## 6. 이 자료 검증에서 완료로 표시하지 않은 항목

- 현재 시즌의 실제 포스트시즌 참가 팀, 각 경기의 확정 시각과 경기장.
- 아직 열리지 않은 2027년 포스트시즌의 실경기 결과.
- 각 시리즈 내부의 모든 경기 날짜: 현재 PDF는 위 기간을 제시하며 개별 날짜는
  공식 경기별 편성 응답을 사용한다. 날짜 간격을 가정하여 확정 경기 행을 만들지 않는다.
- 구현 이후의 자동 MASTER 쓰기·재조회, PR 병합, Pages 반영, 첫 새 예약 실행 결과.
- 운영요강 전체 12쪽의 전 항목을 자동 구조화한 결과 또는 일반 OCR 정확도.

공식 일정·규정 확인과 개별 경기 API 확인은 다른 증거다. 전자는 이번 읽기 검증으로
완료했으며, 후자의 현재 시즌 빈 응답과 향후 실제 편성은 구분하여 처리한다.

## 7. 구현 및 기존 운영 문서·MASTER 적용

- 공식 단계별 수집을 `201/204/202/203`으로 확장했다. 정상 빈 응답과 미확정
  대진을 구분하며, 팀·날짜·시각·경기장이 확정된 공식 경기만 기존 MASTER와 연결한다.
- 기존 정규 252개 ID를 보존하고 포스트시즌은 성별·단계·차전 기반 ID를 사용한다.
  최초 등록은 기존 빈 예약 행 254~271의 지정 셀에만 허용한다.
  도시·개인 메모 열은 쓰지 않고, 쓰기 전 충돌 검사와 쓰기 후 재조회가 성공해야 공개한다.
- 최종 정규 3·4위 승점 차와 공식 순위 대조로 준PO 필요 여부를 확인한다.
  PO 2승, 챔피언결정전 3승 및 진출 경로를 검사한다. 이미 등록된 잔여 차전이
  불필요해지면 `미실시`로 남기고 순위·최근/다음 경기·달력에서 제외한다.
- 실제 MASTER의 빈 포스트시즌 상태 셀 **M254:M271 18개**에만 `미실시` 허용값을
  추가했다. 기존 다섯 상태·strict 규칙을 보존했고, 실제 값과 주변 M253/M272의
  검증 규칙이 그대로인지 재조회했다. 이 작업으로 경기 행이나 결과를 쓰지는 않았다.
- 기존 운영원칙 MASTER v17의 같은 문서 ID에서 대회 운영 묶음 기본 범위를
  마지막 가능 챔피언결정전까지로 보완하고, 해당 문구와 변경 이력을 재조회했다.
