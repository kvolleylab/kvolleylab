# 대표팀 역사 로드맵 · 2015–2017 월드리그 보완 v1

검증일: 2026-11-24 (한국 시간). 기준 main: `f7f7f2fb203064572f8184f5b78b1e94d7d40244`.

사용자의 후속 진행 요청에 따라 지난 점검에서 후보로 남긴 남자 성인 월드리그 3개 대회를 추가한다. 이전 운영 반영 승인 범위에서 검증 후 PR로 반영한다.

## 수록 범위

| 대회 | 대한민국 최종 순위 | 수록 경기 | 남은 확인 사항 |
| --- | --- | --- | --- |
| 2015 월드리그 | 공동 18위 | 전체 12경기, 2승 10패 | 6월 7일·26일 체코전의 세트별 점수 |
| 2016 월드리그 | 23위 | 전체 9경기, 3승 6패, 전 경기 세트별 점수 | 이번 수록 범위 없음 |
| 2017 월드리그 | 전체 18위 / 그룹2 6위 | 공식 결과를 확보한 5경기 및 세트별 점수 | 슬로베니아전 2경기·네덜란드전·슬로바키아전 원문 |

2017년의 수록 경기만으로 전체 승패를 계산하지 않는다. 화면에 `9경기 중 5경기 수록 · 나머지 확인 중`을 표시한다. 2015년의 미확인 세트별 점수는 빈 배열과 필드 검증 상태로 보존하며, 두 경기의 최종 세트스코어는 확인했다.

표시 기간은 월드리그 전체 대회 기간이다: 2015년 5월 16일–7월 19일, 2016년 6월 16일–7월 17일, 2017년 6월 2일–7월 9일. 대한민국 경기 기간 또는 그룹2 결선 기간으로 오인하지 않도록 상세에 범위를 적었다. 경기별 날짜는 개최지 현지 날짜다. 개최지는 상단에 다국가 순회 개최로 표시하고, 확인된 한국 경기 개최 지역은 상세 기록에서 설명한다.

## 출처 대조 및 상충 처리

- JVA 역대 기록의 2015년 `rank18` 동순위 구조와 [2016 참가국 공식 발표](https://www.jva.or.jp/topics/11340/)의 전년도 `18位タイ`를 대조해 **공동 18위**로 확정했다. 순위 목록의 19번째 항목 또는 당시 세계랭킹 23위를 대회 순위로 옮기지 않았다. KVA 구형 역사표의 2016 연도 중복 오기를 그대로 사용하지 않았다.
- [JVA 역대 월드리그 순위](https://www.jva.or.jp/record/nationalteam_men/worldleague/)로 2016년 23위와 2017년 18위를 확인했다. 핀란드배구협회 연감과 KVA의 그룹2 6위는 전체 18위와 범위가 다른 기록이므로 별도 필드에 저장했다.
- 2015년 프랑스전은 FFVB 자료, 일본전은 JVA, 체코전은 ČVS 결과와 FPV 공식 일정을 대조했다. ČVS 시즌 결과의 6월 26일 행에 적힌 연도는 2015 시즌 문맥 및 FPV 2015 일정으로 확인했다. 공식 일정을 근거로 확인된 경기번호만 저장했다.
- 2016년 ČVS 결과표의 F2 날짜에는 하루 차이가 있다. FPV가 보관한 FIVB 공식 일정에 명시된 현지 날짜를 채택했다. 한국의 새스커툰 경기는 **6월 24·25·26일**이다. 세트 점수는 ČVS 결과, 일본전은 JVA와 교차 확인했다. 결과가 비어 있는 다른 팀의 결선 표는 근거로 사용하지 않았다.
- 2017년 6월 2일 체코전 4세트는 ČVS 요약표의 25–19 대신 **FIVB P-2 원본의 25–20**을 채택했다. 원본 총점 112–100과도 일치한다. 네덜란드 개최 도시 역시 사전 예정지 대신 실제 P-2의 **헤이그**를 사용했다.
- TVF 기사 본문은 경기일을 2017년 6월 10일로 명시한다. 사이트 이전 후 표시된 2024년 게시일을 경기일로 사용하지 않았다.
- 접근되지 않는 옛 FIVB 통계 파일은 공식 협회가 보관한 동일 형식의 원문 또는 공식 결과표로 대체했다. Wikipedia·비공식 결과 사이트는 자료 탐색에만 사용했고 수록 결과의 근거로 등록하지 않았다.

모든 출처 URL, 출처 ID, 확인일, 문서 내 위치는 두 JSON에 저장했다. 공식 PDF 전체나 선수별 개인정보는 저장소에 복제하지 않는다. 이번 원문 파일의 Drive 보관은 수행하지 않았으며, 재조회 가능한 공식 URL을 유지한다.

## 기존 기록과 운영 구조 보존

- 기존 **62개 이벤트 객체**, **25개 요약 객체**, 기존 장소 항목과 순서를 SHA-256으로 비교해 보존 여부를 검사한다. 추가 후 65개 이벤트, 28개 요약이다.
- 전체 / 핵심 / 올림픽 / 진출 실패: **65 / 37 / 16 / 17**. 추가 월드리그는 일반 국제대회 기록이며, 올림픽 예선 참가 또는 올림픽 진출 실패로 분류하지 않는다.
- CSS, 연도별 접기·펼치기, 상세 3행 구조, 메뉴, 올림픽 주기 데이터는 변경하지 않는다. 렌더러는 새 상대국의 한글 이름만 추가하고 변경된 모듈의 캐시 버전을 갱신한다.
- `actualParticipation`, `participationConfirmed`, `qualificationOutcomes`, 필드별 검증 상태를 분리한다. 참가·순위는 확정이며, 경기 상세 범위의 미확인은 `matchCoverage`, `fieldVerification`, 안내 문구 및 미확인 목록에 보존한다.
- KVL 대회 MASTER·기존 국제/대표팀 데이터·Google Drive 자료를 먼저 대조했다. 기존 역사 파일의 U18–U23 자료를 성인 기록으로 사용하지 않았다. 새 ID는 기존 로드맵 규칙의 `kor-m-world-league-YYYY`를 사용하며, 확인하지 못한 MASTER 고유 ID나 대회 페이지 링크를 만들지 않는다.
- 기존 완료 대회 중 경기 상세가 미수록인 **32개**는 이번 변경으로 보완되었다고 주장하지 않는다. 이번에는 신규 3개 대회만 추가한다.

## 검증 및 배포

- `node --test tests/*.test.mjs`: **74/74 통과**. 원래 62개 기록·25개 요약 보존, 점수 방향과 세트 득점 규칙, 부분 수록 안내, 필터, 2032 미확정 규정 차단, LA28 보관 구조를 포함한다.
- 공개 JSON 게이트 `validate_changed`: **PASS**. 두 데이터의 출처 목록과 실제 SHA-256이 일치한다.
- PC 실제 콘텐츠 폭 1348px: 세 필터 37/16/17 및 전체 65개, 2015·2016 상세 12/9경기 확인. 기존 상단 1/5/3/3 안내가 정상 표시된다.
- 모바일 프레임 390/360/320px(스크롤바 제외 실제 콘텐츠 폭 375/345/305px): 2017년 5경기 및 부분 수록 안내, 상세·연도 접기/펼치기 정상. 기본·세부 기록 펼침 모두 수평 넘침 0. 실제 휴대전화 기기 검사는 하지 않았다.
- 2032 미리보기는 `공식 출전 규정 발표 전`을 표시하고 2028 출전권 숫자를 재사용하지 않는다. 과거 기록 데이터는 변경하지 않는다.
- 미리보기는 관리형 로컬 환경에서 검증했다. 공개 최종 진입점은 기존 `https://kvolleylab.com/olympic-roadmap.html`을 유지하며 URL/메뉴를 개편하지 않는다.
- 사용자 승인 범위에 따라 PR 검토 후 운영 반영한다. 병합 SHA·GitHub Pages 배포·운영 화면 확인 결과는 해당 PR에 추가 기록한다. 아래 구현 검증만으로 운영 배포 완료를 의미하지 않는다.
