## 변경 범위

최신 main `f7d51ee1264b8f2811fef618e4f01f597acdb154` 재확인. 기존 Draft PR #243의 `dc20e8d0dfcbf95de6d73b20a9fe03247fb29426`, 비공개 시안 v3의 `fabb0d0e7fd0645c3621faad4c94a14e6184211a`를 수정 전 기준으로 보존했다. 이번 작업은 그 시안의 연간 기간 레이어만 개선한다.

- 연간 막대의 대회명 및 작은 남/여 배지를 제거했다. 전체 이름은 접근성 이름과 기존 Dark Navy Tooltip에 유지한다.
- 연간 막대 높이 6px, 세로 간격 3px로 50% 겹침. 계열색은 동일하며 채도/테두리와 Hover 강조만 얇은 막대에 맞췄다.
- 기존 카드와 날짜 그리드의 높이 산정은 유지하고 실제 레이어만 얇게 표시한다. 메뉴·HERO·상단 컨트롤·월 이동·3×4 카드·일요일 시작·색상 정책을 바꾸지 않았다.
- 같은 대회(성별을 제외한 전체 제목, 분류 및 계열 일치)의 남자/여자 시작일과 종료일이 모두 같을 때만 연간 표시 레코드를 하나로 합친다. 원본 2개 ID와 링크는 그대로 보존한다.
- 통합 막대의 Tooltip은 남·여, 두 원본 대회명, 전체 기간, 계열, 각각의 대회 링크를 제공한다. 막대 자체의 기본 이동은 해당 월/날짜로 연결한다. 성별 필터를 선택하면 해당 원본 한 대회·색상·링크로 돌아간다.
- 연령이나 대회명이 다르거나 날짜가 다르면 합치지 않는다. 후보가 중복되어 한 쌍을 특정할 수 없는 경우도 원본을 유지한다.
- 월간보기의 표시 대회명·배지·색상·크기·링크는 그대로다. 데이터·MASTER·기간·대회 ID를 변경하지 않았다. 대회 숨김과 우선순위 재조정은 하지 않았다.
