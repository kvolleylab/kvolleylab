## 표시 변경

대회 행의 이름·성과·금색 진출 관문·붉은 실패 표시를 유지한다. 펼쳤을 때 확인된 일정과 최대 3개의 핵심 항목을 먼저 표시하고, 연결된 KVL 대회에는 `대회 기록 보기` 버튼을 둔다. 기존 영문명·참가 상태·세트 점수·설명·검증 정보·출처·확인일은 `세부 기록·출처` 안에서 그대로 확인할 수 있다. PC는 간결한 가로 행, 모바일은 좁은 항목 열과 세로 버튼을 사용한다.

## 데이터와 원본 보존

- `men-senior-history-v1.json`, 기존 렌더러·모델·CSS와 baseline fixture의 바이트는 base와 동일하다. 기존 62개 대회 ID·순위·참가·출전권·실패·공식 URL·확인일은 수정하지 않는다.
- 새 `men-senior-history-summaries-v1.json`은 16개 주요 기록의 표현 요약이다. 원본의 31개 공개 출처를 그대로 참조하고, 각 요약에 참조 필드의 `basis`를 저장한다. `updatedAt`은 표현 검토일이며 기존 역사 사실의 확인일을 갱신하지 않는다.
- 원본의 참조 필드가 바뀌면 이전 요약을 사용하지 않고 현재 구조화된 경기/경로를 표시한다. 요약 JSON 로딩 실패 시에도 구조화된 정보와 전체 원본 상세는 읽을 수 있다. 원본 데이터 검증 실패·스크립트 실패 시에는 기존 상세 동작을 유지한다.
- 표시 모듈은 원래 `.event-detail` 노드를 삭제하거나 재작성하지 않고 닫힌 `<details>` 안으로 옮긴다. 필터 재렌더링 시 같은 변환을 적용한다. 교차 참조한 예선은 원본 상세 안에 관련 역사 기록 링크도 제공한다.
- 새 요약에 확인되지 않은 경기·상대·점수·미래 참가 결과를 추가하지 않는다. 경기 사실을 새로 조사한 작업이 아니라 이미 검증된 공개 기록의 표현 변경이다. 공식 근거 URL과 당시 확인일은 원본 상세에 남는다.
- Drive 출전권 MASTER와 관련 원본 폴더를 읽기 확인했다. 폴더의 직접 항목은 해당 MASTER이며 2026-07-25 기준의 이전 명칭·대회 전 상태가 남아 있다. 이번에는 이후 공식 검증을 반영한 운영 역사 JSON을 기준으로 하며 MASTER·Drive 파일·경기 자동화는 쓰지 않는다. 원본 문서/PDF를 공개 복제하지 않는다.
