## 구현

공통 `selectMatchSummary`/`matchSummaryState`를 홈·V-리그가 사용한다. 홈의 명시적 결과 검수 조건과 대회의 기존 유효 결과 호환성을 유지한다. 취소/연기/잘못된 날짜·시각·미등록 팀 제외, KST 경계, 다중 경기 우선순위, 종료 결과 중복 방지를 검사한다. 새 점수는 공식 일정의 진행 판정·세트 승수·경기 연결 키·관측 시각을 가진 `liveScore`로만 전달하고 최종 score/승패/순위에는 넣지 않는다. 30분 경과 시 갱신 지연, 유효 관측 없으면 상태 확인 중이다. 경기 종료 시 임시 스코어를 제거한다.

기존 수집 일정과 MASTER/전체 시즌 게시 검증을 유지한다. 진행 중 실제 재관측 시각 갱신만 허용하며 동일 관측 재실행은 변경0이다. 브라우저는 보이는 동안 5분 JSON 재조회/1분 날짜·지연 계산, 다시 보일 때 재조회하며 실패 시 기존 자료를 보존한다. 동일 내용이면 DOM을 교체하지 않는다. 포인트·현재 세트 번호는 추정하지 않는다.

변경 파일: 홈 HTML, 공통 데이터 선택기, 국내대회 요약 JS/CSS, 엔진 캐시 버전, 공식 updater의 liveScore export, 관련 테스트/Quality Audit 등록, 운영 명세와 결정/검수 기록. 실제 경기 데이터·ID·명단·이미지·메뉴/검색·달력·기존 순위 산식은 직접 수정하지 않는다.
