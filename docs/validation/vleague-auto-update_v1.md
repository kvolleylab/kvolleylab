## 복구

운영 전에는 PR을 수정하거나 닫으면 된다. 운영 후 이상이 발견되면 활성화 변수를 false로 설정하고 현재 실행을 취소한 뒤, MASTER·커밋·공개 JSON을 대조한다. MASTER가 먼저 반영된 경우 올바른 확정 결과를 지우지 않고 재실행으로 사이트 반영을 마무리한다. 출처 정정·수동 잠금 충돌은 자동 해제하지 않는다.
