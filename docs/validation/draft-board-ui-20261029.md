## 추첨 방식과 확률의 의미

사용자 정정 기준이며 공식 시행세칙 확인으로 표기하지 않는다. 각 수치는 해당 단계 시작 시의 구슬 비율이다. 이미 나온 팀을 중복 재추첨하는 과정까지 고려한 최종 순위의 확률은 아니다.
