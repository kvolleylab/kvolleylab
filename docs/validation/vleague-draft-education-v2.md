# K-Volley Lab · 2026-27 신인 등록 검수 화면 v2 — 학교 이력 선택 표시

상태: **공식 원본 대조·독립 브리지 CI PASS / 독립 HTML 검수 화면 PC·모바일 검증 / PR #332 검수 중 / 운영 미배포**.

## 요청과 표시 기준

- 일반 이용자에게 불필요한 Player_ID, 검수 내부 상태, 기술적 자료 구분, 빈 학교 항목을 기본 선수정보 화면에서 숨긴다. 출처 링크는 접어서 제공하며 필요할 때 열 수 있게 한다.
- 학교 이력은 `출신 고등학교`와 `출신 대학교`로 구분한다. **실제 확인된 항목만** 표시한다. 중학교, 군부대·시청팀 등 직전 소속은 임의로 고등학교나 대학교로 분류하지 않는다.
- 대학 출신 드래프트 선수는 고교 + 대학을 모두 표시할 수 있다. 고교 직접 지명자는 고등학교만 표기하며 대학교를 추측하지 않는다. 산업체 선수도 공식 자료의 고교·대학 이력이 확인된 경우에만 해당 학교를 표기한다.
- 본문 `current_roster.team_name`, 선수 영구 ID, 과거 실제 대회 출전 명단은 수정하지 않는다. 학교 출신 이력은 선수 현재 구단이나 입단 효력일과 구분한다.

## 데이터 출처와 검증

- 원본: 남자 `data/draft-applicants/2026-27/list-details.json` (KOVO-2026-27-M-157978), 여자 `women-list-details.json` (KOVO-2026-27-W-157977). 2026-10-30 기준 공식 PDF 검증 결과를 사용한다.
- 대조: `applicant_id`, 정확한 이름, 성별, `affiliation`, 행 순서, 생년월일의 연도를 `applicants.json`과 비교하고 원문 SHA-256을 확인한다.
- 원본 117명 중 출신 고교·대학 중 적어도 한 항목이 확인된 116명만 별도 공개 원장 `data/draft-applicants/2026-27/education-v1.json`에 수록. 이 중 고교 111명, 대학 59명, 둘 다 54명이다. **이것은 드래프트 신청자 기준이며 실제 프로 등록 인원이 아니다.**
- 현재 공식 등록 연결 대상은 별도 `draft_registration_bridge.json`의 32명이며, 검증 `applicant_id`와 이름·성별이 정확히 일치하는 경우에만 교육정보를 연결한다. 기존 신원 매핑 28건, 보류 6건은 유지한다.
- 실제 예시: 윤경 남성고·인하대, 임인규 수성고·인하대, 전유석 문일고·중부대, 김아중 청수고만, 이율리는 출신 고교·대학 둘 다 공식 자료에서 확인되지 않아 표시하지 않음.
- 페이지의 `assets/js/kvl-vleague-draft-bridge-v1.js`는 교육 원장이 없거나 잘못되면 기존 등록 선수명단을 그대로 유지하고 학교 항목만 생략한다. 학력 대조 실패가 기존 경기결과·명단을 훼손하지 않는다.

## 향후 운영 반영

- PR #332에서 UI/CI 검수와 다른 운영 변경 충돌이 해소되고 사용자가 배포를 승인한 경우에만 운영 반영한다.
- `source` 파일이 정정되면 학교 스냅샷의 원문 SHA와 검수 원장을 다시 비교하고, 변경 사실의 출처·영향 범위를 확정한다. 이름만으로 학교 이력을 자동 합치지 않는다.
- 미확인 학교를 표시하지 않는 동작을 실제 PC/모바일 홈페이지에 동일하게 적용하고 배포된 JSON·브라우저 화면을 확인해야 `DEPLOYED`다.
