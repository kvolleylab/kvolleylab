# V-리그 조견표 승점 기준 v5

2026-11-15 KST · USER CLARIFIED / IMPLEMENTED / LOCAL QA VERIFIED / RELEASE AUTHORIZED

사용자는 상대팀 칸에 **경기에서 획득한 승점**, R승점에 **해당 라운드 합계**, 총점에 **모든 라운드 합계**를 표시하도록 정정했다. 기존 운영 연결 승인 범위의 표시·계산 수정이다. v4의 상대팀 칸 세트 승수 및 라운드 시점 총승점 정의를 이 범위에서 대체한다.

## 동작

- 3–0·3–1: 승리 팀 3점, 패한 팀 0점. 3–2: 승리 팀 2점, 패한 팀 1점. 홈·원정 양쪽에 동일 규칙 적용.
- 상대팀별 승점의 가로 합 = R승점. 모든 라운드 R승점 합 = 시즌 총점.
- `총점`은 현재까지 종료된 정규리그 전체 경기의 승점으로, 6개 표에 동일하게 표시한다. 미시작 라운드의 R승점과 상대팀 칸은 공란이다.
- 순위는 기존대로 해당 라운드까지 누적 결과 기준이다. 총점과 순위의 기준은 설명 문구에 구분한다.
- 0은 승점 미획득, 공란은 미진행. 고정 팀 순서·대각선·PC 2×3·모바일 1열과 기존 디자인은 유지한다.
- 결과 수정 시 다시 계산하며, 별도 DB나 갱신 요청·타이머를 추가하지 않는다. 기존 결과 수집·발행·정규리그 순위·명단 데이터는 변경하지 않는다.
