## 표시 계약

| 현재 달력 범위의 당일 경기 수 | 칸 안 | 날짜 선택 |
|---|---|---|
| 0 | 날짜만, 음영 없음 | 팝업 없음 |
| 1 | 실제 단계 + 홈팀 `vs`/등록 세트 결과 원정팀, 다음 정보 줄 `(장소, KST 시간)` | 그 경기의 팀·시간·장소·세트 점수 |
| 2 이상 | `N경기`, 실제 결승이 있으면 `결승 포함` | 해당 날짜의 모든 경기를 시간순으로 표시 |

전체 대회 달력과 선택 팀 달력은 각자의 경기 범위로 수를 센다. 예: VNL 남자부 8월 2일은 전체 달력에서 `2경기`, 미국 선택 시 `결승 미국 2-3 폴란드`와 경기장/시간이다. 선택 팀의 전체 경기 목록은 계속 기본 펼침이다. 미실시(`not_required`) 차전은 제외한다.

종료 상태(`final`/`completed`)와 유효한 등록 점수 또는 기존 승인 Snapshot의 상태 필드 없는 확정 점수만 결과로 표시한다. 명시적인 예정·진행 중·취소 상태에 남은 점수로 완료를 추정하지 않는다. 날짜로 결과를 만들지 않는다. 일반 결승을 V-리그 챔프전으로 바꾸지 않는다.

요일은 7열을 유지한다. 모바일에서 긴 팀명·경기장은 필요한 만큼 줄바꿈한다. 두 줄은 정보 묶음 기준으로 정확히 두 개의 물리적 행에 강제하지 않는다. 말줄임, 경기 텍스트의 흰 내부 카드/왼쪽 띠, 페이지 가로 스크롤은 없다. 평일 날짜는 검정, 일요일/한국 공휴일은 빨강이며, 경기 있는 날짜만 음영을 넣는다. 공휴일 경기 음영은 연한 빨강이고 나머지 경기 음영은 기존 대회 색상이다.
