# K-Volley Lab 팀찾기 PC 3열·모바일 2열 카드 배치 검증 v1

**2026-11-20 · 사용자 "진행해" 승인 범위**

## 목적과 기준
- 사용자 승인: `팀찾기`에서 PC는 한 줄에 3개 팀 카드, 모바일은 한 줄에 2개 팀 카드. 사전 검토 답변의 권장 설계에 따라 중간 화면을 별도 취급.
- 미디어 구간: **1280px 이상: 3열 가로형 / 661~1279px: 2열 가로형 / 660px 이하: 2열 세로형**.
- 팀찾기의 **목록 카드**에만 적용한다. 프로 선수 로스터의 표/카드, 국가대표 통합명단·대회별 명단, 홈, 관리자 페이지, Supabase 개인 계정 화면은 그대로 둔다.
- 모바일에서 이미지·로고를 상단 중앙에 배치하고, 아래에 분류/팀명/감독·인원·출처 등 기존 정보를 표시한 뒤, 하단에 최소 44px 높이의 액션 버튼을 둔다. 팀명/국가명은 원본 글자를 줄이거나 숨기지 않고 여러 줄로 표시. 국가 국기 40개 SVG, 기존 구단 로고 URL은 재사용한다.
- PC 3열에서 기존 카드 내부 **31% 로고 + 69% 텍스트** 구조는 유지하고 패딩·글씨만 카드 너비에 맞춰 조정. 모든 카드는 동일한 행에서 높이가 늘어나며 버튼이 카드 하단에 배치된다.
- 360/390px 모바일 카드: 실제 공간이 좁아 분류/팀명/정보/명단 버튼 간격을 축소하되 팀명은 14~15px, 출처 정보 10~10.5px, 명단/팀정보 버튼 10.5~11px; 버튼 최소 46px로 터치 범위는 유지.
- 상단 Team Finder HERO는 PR #383에서 홈 PC/모바일과 동일하게 반영한 원본 WebP를 계속 재사용한다.
