## 반영 범위

기존 공개 MASTER와 대학 명단의 이름을 기존 ID로 한정하여 정정했다. `data/changelog/player_corrections_v1.json`에 이전 이름·새 이름·공식 근거·파일별 변경 위치를 추가했다. 과거 MASTER 버전과 seed는 보존했다.

신청자 6명을 동일 ID에 연결했다. 신청 당시 학교·학년·포지션은 신청 기록에 유지하며, 기존 프로필의 포지션·키·소속 이력을 덮어쓰지 않았다. 장승호의 과거 MB와 신청 당시 OP 표기도 별개로 유지한다. 김관응 `KVL-P-000188`, 다른 이소민 `KVL-P-000753`, 경희대·한양대 이수민은 변경하지 않았다.

HTML·JS·CSS·공통 메뉴·홈·경기 결과는 변경하지 않았다. 회원 기능 PR #155는 포함하지 않았다.

## Google Drive MASTER

[기존 선수 MASTER](https://docs.google.com/spreadsheets/d/1CecA9AXRiAaQw44Cvgo8Xo2WQXwALAhV/edit)의 파일 ID와 폴더를 유지했다. 옹민혁·전유석·송건환은 이미 정정돼 있어 재확인 기록만 추가했다. 염시원·장승호·이소민의 이름 3셀, 6명의 검수일·근거 12셀만 수정했다. 기존 근거는 삭제하지 않고 뒤에 추가했다.

수정 전 [원본 백업](https://docs.google.com/spreadsheets/d/1Eln3vBH7QWeQNo9t7NJZOoQAxIfbU0RT/edit)을 같은 폴더에 저장했다. 1,462개 ID·기존 셀 서식·시트·검증 규칙·수식·다른 ZIP 구성요소를 보존했다. 다시 내려받은 파일의 SHA-256이 검증본과 일치한다. 로컬 렌더러에는 한글 글꼴이 없어 한글 표시의 시각 검증은 제한되었으며, 셀 값과 원본 서식은 별도로 대조했다.
