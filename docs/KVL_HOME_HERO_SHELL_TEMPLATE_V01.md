# KVL HOME HERO SHELL — 기본 양식 v01 (2026-10-14)

상태: **홈 UI 프로토타입 기준**. 기존 `index.html` production은 수정하지 않는다. 사용자가 디자인 승인한 뒤 적용한다.

## 시각적 원본 (Source of Truth)
- 실제 대회 공통 구조: `assets/js/kvl-competition-shell-v2.js` — `.kvl1180-hero`, `.kvl1180-controlbar`, `.kvl1180-tabs`.
- 지오메트리: `assets/css/kvl-competition-geometry-v2.css`.
- `competition-engine.html?competition=v-league-men-2026-27`의 검증된 Hero 및 하단 컨트롤바. Home에서 competition shell의 대회 데이터/탭을 그대로 복제하지 않으며, **형태만 동일**하게 반영한다.

## 필수 형상
1. 콘텐츠 최대 폭 **1180px**. 기존 PC 좌측 고정 사이드바 210px / 접힘 76px; 화면에 같은 글로벌 메뉴를 두 번 만들지 않음.
2. 상단 Hero는 페이지 콘텐츠 맨 위에 밀착. **윗모서리 직각**(`border-radius:0`, `border-top:0`), full-width within 1180 content. 헤더 위에 뜨는 별도 라운드 카드 금지.
3. Hero 바로 아래에 흰색 **일체형 controlbar** — `margin-top:0; border-top:0; border-radius:0 0 10px 10px; overflow:hidden`. Hero와 아래 바가 한 덩어리처럼 보이게.
4. Hero 속 메시지/탐색, 하단 바에서 섹션 점프. 사이드바를 복제하는 8개 메뉴바가 되지 않도록 최대 4개 홈 내부 섹션(경기 일정·결과 / 최근 대회 / 선수·팀 / 도구·자료)으로 제한.
5. **정확도 > 탐색 속도**: 확인된 자료만 경기 결과로 표시. 미확인 경기는 점수 임의 생성 금지; 경기 미개최 / 결과 미확인 / 데이터 갱신 중 분리. 원천자료 링크와 확인 시각 노출. 공통 Competition Engine의 검증된 데이터 사용; UI용 하드코딩 경기 금지.
6. 최근 대회는 기존 규칙인 최근 국제대회 3개 자동 노출을 존중, 대회별 보기로 나머지 접근. 실제 이미지 자산을 임의 CSS 색상 플래그로 대체하지 말 것. 홈에는 작은 카드가 모바일 대회 자산을 동적으로 참조하는 구조를 검토.
7. 중복 정보 노출 방지: 상단 Hero와 하단 '검색 바로가기' 및 섹션별 카드에 같은 탐색 메뉴 중복하지 않음.
8. 모바일 390/360 기준: 글로벌 사이드바는 기존 모바일 메뉴 그대로; Hero/하단 바 연속성 유지, 탭 2×2 배치 가능, 손가락 터치 44px 이상, 페이지 전체 가로 스크롤 금지.
9. 홈 시안은 운영페이지와 별도. `index.html`, 글로벌 사이드바, AVC/VNL 등 production 의존성 수정 금지.

## UI 정보 순서
Home Hero(정확한 배구 정보를 빠르게 찾는다 + 메뉴/대회 찾아가기, 실제 선수 풀텍스트 검색이라고 주장하지 않음) → Hero에 붙은 4개 섹션 탭 → 검증된 최근 결과/다가올 경기 → 최근 국제대회 3개 → 선수/팀/국가대표 → 도구/자료 → 수정 요청.

## 승인 게이트
PC 1180, 모바일 390/360 스크린샷 비교; Hero 상단 직각/하단만 10px 라운드; 사이드바 중복 없는지; 실제 데이터 출처·시각 및 미확인 상태 표기; 링크 유효성 확인. 이 후 명시적 지시가 있을 때만 실홈 적용.
