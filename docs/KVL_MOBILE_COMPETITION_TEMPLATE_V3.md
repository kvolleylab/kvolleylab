# K-Volley Lab 모바일 대회 페이지 기본 템플릿 v3

## 목적

K-Volley Lab 모바일 대회페이지를 **대회 데이터·테마만 바꾸면 동일한 UI로 재사용**할 수 있도록 구조뿐 아니라 글씨 크기, 행 높이, 이미지 크기, 카드 간격, 상태 전환까지 공통 규격으로 고정한다.
특정 실제 대회 페이지는 Source of Truth가 아니다.

## Source of Truth

- 규격 문서: `docs/KVL_MOBILE_COMPETITION_TEMPLATE_V3.md`
- 신규 HTML 시작점: `templates/competition-page-v1.html`
- 공통 대회 UI: `assets/css/kvl-competition-template-v1.css`
- 모바일 세부 UI 규격: `assets/css/kvl-mobile-competition-template-v2.css`
- 공통 렌더러: `assets/js/kvl-competition-template-v1.js`
- 데이터 예시: `data/competitions/_template/competition-v1.template.json`

`assets/css/kvl-mobile-competition-template-v1.css`는 기존 페이지 호환용 이전 규격이며, 신규·정리 대상 페이지는 v2 세부 UI 규격을 우선한다.

## 1. 검수 기준

- 모바일 기준폭: 390px.
- PC는 별도 레이아웃으로 유지한다.
- 모바일 수정이 PC에 영향을 주지 않게 `max-width:680px` 범위로 제한한다.
- 특별한 표를 제외하고 가로 스크롤 금지.
- 페이지별 임의 글씨크기·행높이·국기크기 추가 금지. 공통 규격을 먼저 수정한다.

## 2. 상단/메뉴

- 메인 제목: 24px.
- 영문 부제: 12px.
- 날짜 / 장소 / 경기장은 390px에서 각각 1줄 사용 가능. 3개가 함께 자연스럽게 들어가지 않으면 총 3줄로 고정.
- 메뉴 6개: 3 + 3, 높이 42px, 글씨 13px.

## 3. 한눈에 보기

- KPI: 2×2, 카드 최소높이 92px, 값 29px.
- 장소카드: KPI 아래 전체폭, 최소높이 92px.
- 장소카드 구성: `장소` / `국가 도시` / `경기장`.
- 장소 주요값: 20px.
- 경기장 뱃지를 별도로 만들지 않는다.

## 4. 월간 달력

- 7열 전체 월 표시, 가로스크롤 금지.
- 날짜: 10px.
- 경기 수: 8px.
- 경기시간: 8px.
- 날짜 선택 시 경기일정의 해당 날짜로 이동.

## 5. 경기일정

- 경기시간: 13px.
- 팀명: 12px.
- 중앙 세트스코어: 18px.
- 세트별 스코어: 10px.
- 국기/로고: 32px 기본 프레임 안에서 동일비율 유지.
- 단계 필터 6개는 한 줄 우선.

## 6. 조별순위 / 예선 종합순위

남녀·대회별로 **동일 숫자 규격**을 사용한다.

- 헤더: 10px.
- 행 높이: 54px.
- 종합순위: 13px.
- 국가/팀명: 13px.
- 세부통계: 11px.
- 국기: 28×19px.
- 열 간격: 6px.
- 헤더와 값은 각 열의 중앙선에 정렬.

진행상태에 따른 열 순서:
- 조별리그 진행 중: `종합순위 / 국기 / 국가 / 조순위 / 승리 경기수 / 승점 / 세트 득실률 / 득점 득실률`
- 조별리그 종료 후: `종합순위 / 국기 / 국가 / 결과 / 승리 경기수 / 승점 / 세트 득실률 / 득점 득실률 / 조순위`
- 완료 여부는 데이터의 조별리그 전체 경기 완료 상태로 자동 판단한다.

완료 후 결과뱃지:
- 진출뱃지: 62×26px.
- 시드쌍 숫자: 11px.
- 탈락뱃지: 진출뱃지와 동일크기.
- 테마색은 CSS 변수로만 달라지고 크기는 동일.

## 7. 최종순위 / 결선 토너먼트

### 확정 경기
- `국기 + 팀명 + 스코어 + 팀명 + 국기` 한 줄을 우선한다.

### 아직 확정 전인 QF 예상대진
한 경기 카드 안에서 좌우 대칭으로 표시한다.

왼쪽:
- `국기 + 국가명`은 하나의 identity 블록.
- identity 블록 오른쪽에 2줄 메타정보.
- 위: `현재 예상` 또는 `확정`.
- 아래: `예선 종합 n위`.
- 국기+국가명은 두 메타줄의 세로 중앙에 위치.

오른쪽은 좌우 반전한다.

규격:
- 국가명: 13px.
- 국기: 30×21px.
- `현재 예상/확정`: 9px.
- `예선 종합 n위`: 9.5px.
- VS: 10px.

## 8. 참가국/참가팀

- 2열 카드.
- 카드 최소높이 64px.
- 국기/로고 35×24px.
- 한글명 12px.
- 영문명 9px.
- 조/부문 뱃지 9px.

## 9. 색상

- 레이아웃과 테마색을 분리한다.
- 남자/여자/국내/국제 차이는 CSS 변수로만 처리한다.
- 페이지별로 같은 역할의 요소에 별도 색상·크기 CSS를 만들지 않는다.
- 대회 고유색은 `primary/dark/line/soft` 등 테마변수만 변경한다.

## 10. 개발 원칙

- 실제 대회 HTML 안에 공통 모바일 숫자값을 추가하지 않는다.
- 두 페이지의 같은 컴포넌트 크기가 다르면 페이지별 수정이 아니라 `kvl-mobile-competition-template-v2.css`를 수정한다.
- 신규 MutationObserver로 레이아웃을 패치하지 않는다.
- 데이터/대회규정 차이는 renderer/data에서 처리하고, 시각 규격은 공통 CSS에서 처리한다.
- 새 대회는 `templates/competition-page-v1.html`에서 시작한다.

## 버전 이력

- v1: 모바일 구조 초안.
- v2: 특정 실제 대회를 기준본으로 지정하지 않는 독립 템플릿 원칙 확정.
- v3 / 2026-09-07: 구조뿐 아니라 글씨 크기·행 높이·국기 크기·뱃지 크기·예선종합순위 상태전환·QF 예상대진 내부배치까지 수치로 고정. `assets/css/kvl-mobile-competition-template-v2.css`를 모바일 세부 UI Source of Truth로 추가.
