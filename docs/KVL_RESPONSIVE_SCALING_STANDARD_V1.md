# K-Volley Lab Responsive Scaling Standard v1

## 목적
K-Volley Lab의 PC·모바일 페이지가 특정 한 가지 화면 폭에서만 정상적으로 보이지 않도록 하고, 같은 디자인 구조를 유지하면서 사용자의 실제 브라우저 폭에 맞춰 글씨·아이콘·간격·카드 크기가 자연스럽게 축소·확대되도록 한다.

## 기준 폭
- PC 대회 기본 기준: 1180px 콘텐츠 폭
- 모바일 대회 기본 기준: 390px
- 모바일 보조 검수: 360px

기준 폭은 디자인의 최대/대표 기준이며 고정 렌더링 폭이 아니다.

## 공통 원칙
1. PC와 모바일 모두 고정 px 값만 사용하지 않는다.
2. 가능한 요소는 `clamp()`를 사용해 폰트, 아이콘, padding, gap, 카드 높이를 유동적으로 조정한다.
3. 표·달력처럼 내부 칸 폭이 중요한 컴포넌트는 필요 시 CSS Container Query(`container-type`, `cqw`)를 사용해 실제 칸 크기에 맞춰 글씨를 조정한다.
4. 좁은 화면에서도 먼저 같은 디자인 구조를 유지한 채 비율을 줄인다.
5. 정보가 읽을 수 없을 정도로 작아질 때만 명확한 breakpoint에서 구조를 재배치한다.
6. PC에서는 1180px보다 좁은 브라우저에서도 주요 1행 구조가 쉽게 줄바꿈되거나 잘리지 않도록 우선 유동 축소한다.
7. 모바일에서는 390px과 360px 모두 가로 페이지 스크롤이 발생하지 않도록 한다. 단, 의도적으로 넓은 데이터 표 등 별도 스크롤 컴포넌트는 예외로 한다.
8. 텍스트는 가능한 한 `white-space`, `minmax(0,1fr)`, `overflow`, `text-overflow`를 조합해 레이아웃 붕괴를 방지한다. 중요한 국가명·선수명 등은 먼저 폰트가 자연스럽게 축소되도록 설계한다.
9. 동일 컴포넌트의 PC/모바일 디자인 언어(색상, 위계, 아이콘 의미)는 유지한다.

## 대회 페이지 적용
- PC: 1180px에서 가장 시원하게 보이고 1024px대까지 같은 카드/탭/KPI 구조를 우선 유지한다.
- 모바일: 390px에서 기본 완성형, 360px에서 자동 축소 검수한다.
- 상단 Hero, 탭, KPI, 랭킹, 토너먼트, 선수명단, 월간 달력 모두 이 원칙을 기본값으로 한다.

## 현재 기준본
- PC 후보 기준본: `international-competition-avc-men-continental-2026-pc-hybrid-1180.html`
- 모바일 기본 템플릿: `templates/competition-page-v1.html` 및 관련 공통 모바일 CSS/JS

향후 PC 기본 템플릿 승격 시 이 문서를 공통 설계 기준으로 함께 참조한다.
