# K-Volley Lab 대회 페이지 기본 템플릿 v1

## 목적
2026 AVC 남자 대륙선수권 PC+모바일 프로토타입에서 확정한 화면 구조와 상호작용을 K-Volley Lab의 신규 대회 페이지 기본 템플릿으로 동결한다.

이 문서의 기준은 실제 AVC 남자 페이지 자체가 아니라, 아래에 별도로 저장한 `templates/competition-page-pc-mobile-v1.html`과 이 문서이다. 실제 대회 페이지는 회귀검수 대상이다.

## 동결 기준 시점
- 기준 대회: 2026 AVC 남자 대륙선수권
- 기준 GitHub main: `73f9203eba16256bc4bbddc38a650f8e27e8b6f4`
- 기준 페이지: `international-competition-avc-men-continental-2026-pc-hybrid-1180.html`
- 템플릿 스냅샷: `templates/competition-page-pc-mobile-v1.html`
- 템플릿 매니페스트: `templates/competition-page-pc-mobile-v1.manifest.json`

9. 최종순위 + 결선 토너먼트

11. 공식자료

## PC 기준
- 콘텐츠 최대폭 1180px.
- `대회 한눈에 보기` 우측의 `우승팀 / 국제 진출권` 결과 묶음 왼쪽에는 3px 세로 구분선을 유지한다. 남녀부 모두 동일 구조이며 성별 테마색만 적용한다.
- 한눈에 보기의 클릭 가능한 KPI 카드는 hover 시 자연스럽게 상승하고 그림자가 깊어져 클릭 가능성을 표현한다.
- 장소 카드는 일반 KPI와 동일한 시각계층을 유지한다.
- 최종순위 1~4위 카드는 국기·국가명·결과 영역의 수직 기준선을 동일하게 유지한다.
- 경기결과 스코어는 중립 짙은 회색 `#4B5563`을 기본값으로 사용한다.
- 금색은 우승·메달·올림픽 직행 등 특수 강조에만 사용한다.

## 모바일 기준
- 390px 우선, 360px 보조 검수.
- 6개 메뉴는 3+3.
- `대회 한눈에 보기` 결과 묶음의 세로 구분선은 모바일에서도 유지한다.
- 가로 스크롤은 특별한 표를 제외하고 금지한다.
- Hero 제목 24px, 여자부와 동일한 타이포 규격을 사용한다.
- 장소는 지역과 경기장을 2줄로 표현할 수 있다.
- KPI 핵심값은 동일한 진한 네이비 계열로 통일한다.
- 선수명단은 한국어 이름 우선, 영문명 보조. 선수 카드 글씨는 과도한 굵기를 피한다.
- 공식자료는 모바일 1열 카드로 제공한다.

## 페이지 활성화·데이터 로딩 안정성
- 6개 메뉴의 활성 상태와 해당 view 표시/숨김은 대회 데이터 fetch 성공 여부와 분리한다.
- 공통 `assets/js/kvl-competition-view-bootstrap-v1.js`에서 `?view=` 값을 기준으로 탭 활성 상태와 view 표시를 우선 처리한다.
- 월간 달력은 대회 데이터 renderer가 정상 동작할 때 자동 생성한다.
- 데이터 renderer 지연으로 달력이 비어 보이는 대회는 동일 데이터를 읽는 경량 fallback/guard를 둘 수 있으나, 장기적으로는 공통 renderer 안으로 흡수한다.

## Hero 배경
- Hero는 대회마다 독립 배경 이미지를 사용할 수 있다.
- 배경 이미지는 카드 전체에 넓게 사용하고, 별도 장식 스티커처럼 작게 배치하지 않는다.
- 왼쪽 텍스트 안전영역의 가독성만 필요한 만큼 그라데이션 오버레이를 사용한다.
- PC는 `cover`를 기본값으로 하고, 모바일은 피사체 위치에 따라 별도 position/size를 조정한다.
- 현재 기준 대회는 `assets/img/competition-hero/kvl-hero-avc-men-user-photo-v1.webp`를 사용한다.
- 새 대회에서는 배경 이미지만 교체하고 Hero 정보 구조는 유지한다.
- 상세 자산 기준은 `KVL_COMPETITION_HERO_IMAGE_GUIDE_v1`을 따른다.

## 데이터/상태 원칙
- 대회별 국가명, 일정, 장소, 참가국 수, 조 수, 경기 수, 진출팀, 우승팀, 출전권 문구를 템플릿에 하드코딩하지 않는다.
- `upcoming / active / completed` 상태에 따라 Hero 상태와 한눈에 보기 결과문구가 자동 전환되도록 발전시킨다.
- 다음 대회 진출권은 장기적으로 `qualification` 데이터로 관리하고, 화면에서는 짧은 상태표시로 노출한다.

## 선수명단/회원기능 준비
- 선수는 이름 문자열이 아니라 Player ID를 유지한다.
- 향후 로그인 회원별 선수 체크 기능을 붙일 수 있도록 선수 카드 구조에서 Player ID와 action slot을 보존한다.
- 회원별 체크·관찰 메모는 공개 GitHub/JSON에 저장하지 않는다.

8. Player ID/선수명단 연결 확인

10. 회귀검수 후 배포

## 주의
- `templates/competition-page-pc-mobile-v1.html`은 현재 완성형 디자인을 보존한 기준 스냅샷이다. 새 대회에 그대로 배포하기 전에 AVC 남자 고유 데이터와 링크를 반드시 분리한다.
- 실제 신규 대회 생성용 범용 renderer/data 템플릿은 이 기준을 바탕으로 단계적으로 승격한다.
- 실제 대회 페이지에서 임시로 추가한 CSS/JS 패치가 공통성이 확인되면 공통 파일로 이동하고, 특정 대회 전용 하드코딩은 기본 템플릿에 누적하지 않는다.
