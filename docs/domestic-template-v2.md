# Domestic Template v2 — Home presentation

## 2026-11-01 · VNL 기준 글자 크기·팀 달력 상세 표시 (후속 요청)

- 국제 기본 템플릿은 현재 2026 VNL 시안을 기준으로 정한다. [국제 기준](international-template-v2.md)에 공통 표시와 대회별 규정을 구분한다. 운영 반영은 별도 승인 전까지 하지 않는다.
- 국내 메인 Hero 제목은 VNL과 같은 PC `clamp(30px, 2.45vw, 38px)` / 모바일 `24px`다. 부제는 `15/12px`, 날짜·장소는 `14/11.5px`, 상단 영문 분류는 `11/10px`, 상태는 `11/9px`(PC/모바일)로 맞춘다. 기존 국내 색상·이미지·줄 배치·폰트는 유지한다.
- 선택 팀 달력의 날짜에는 경기 전 `홈팀 vs 원정팀`, 스코어가 등록된 경기는 `홈팀 3-1 원정팀`을 표시한다. 날짜로 종료 여부를 추정하지 않는다. 한 날짜에 여러 경기면 모두 표시한다. PC는 가로 배치, 모바일은 이름 → 스코어 → 이름의 세로 배치로 긴 이름을 생략하지 않는다.
- 선택 팀 달력과 전체 목록은 둘 다 기본으로 펼친다. 날짜 팝업·세트 점수·팀을 유지한 목록 이동·독립 월 이동은 유지한다. 한눈에 보기의 전체 대회 달력은 기존 요약 표시를 유지한다.
- 단일리그에 `structure.standings.showStatus: false`를 지정하면 중복 상태 열을 없애고 결과 열을 남긴다. 기본값과 조별순위의 조 열은 유지한다. VNL 미리보기만 이 옵션을 선택한다.

## 2026-11-01 · 경기행 정렬·팀 달력 보완안 (별도 브랜치, 운영 미반영)

사용자의 VNL 시안 피드백 3·6·8번에 따라 국내 기본 템플릿에도 같은 동작을 준비한다. `feature/vnl-domestic-template-v1` / Draft PR #216의 변경이며, 아래 규칙을 운영 배포 완료로 해석하지 않는다. 국제 기본 템플릿의 최신 기준 채택은 바로 아래 후속 결정과 `international-template-v2.md`를 따른다. 별도 대안 PR #212는 병합하지 않는다.

- PC 경기행은 시간 150px / 가변 대진 영역 / 세트 점수 285px의 세 영역을 사용한다. 대진은 가운데 영역 중앙에 두고, 세트 점수는 항상 5칸을 확보한다. 3·4·5세트 경기에서 팀 로고·이름·전체 스코어가 좌우로 움직이지 않는다. 긴 이름은 줄바꿈하며 모바일은 시간 → 대진 → 세트 점수 흐름을 유지한다.
- 단계·경기장·현지시간의 보조 행은 전체 세트 스코어와 같은 중심축에 한 줄로 표시한다. 좁은 화면에서 길어지면 이 행 안에서만 가로 스크롤한다.
- 일반 토너먼트 경로는 실선이다. `.is-bye` 또는 `.is-direct-entry`가 실제 있는 쌍에만 부전승용 금색 점선을 적용한다. 원래 대진 순서·진출 계산·부전승 데이터는 유지한다.
- 경기 목록의 로고·팀명으로 `view=team&team=...`에 진입하면 해당 대회의 선택 팀 경기만 월간 달력으로 먼저 보여준다. 전체 경기 목록도 달력 아래에 기본으로 펼쳐 둔다. 사용자가 직접 접을 수 있다. 날짜 팝업과 목록 링크에서도 선택한 팀을 유지하며, 기존 선수명단 링크는 유지한다.
- 팀 달력과 한눈에 보기 달력은 같은 렌더러를 사용하되 월 선택 상태는 분리한다. 팀 달력의 범위는 그 팀의 실제 경기 월이며, 종료 후 그 팀의 마지막 경기 월을 연다. 경기 데이터와 식별자는 복제·수정하지 않는다.
- 기존 국제 Hero 보존이 필요한 검토 시안은 `structure.heroPresentation: preserve`로 원래 제목·날짜·장소·상태·이미지 스타일을 유지할 수 있다. 국내 기존 config는 변경하지 않으며 기본 Hero 동작도 유지한다.

공통 변경 파일은 `assets/js/kvl-domestic-home-v2.js`, `assets/css/kvl-domestic-home-v2.css` 및 팀 화면 후처리/부전승 선택자만 보완한 `kvl-competition-components-v2.js/.css`다. 엔진을 복제하지 않는다. [시안 및 검수 결과](validation/vnl-domestic-template-v1.md).

## 적용 범위

- 고성·단양·대학 U-리그 2026 남대부/여대부, 총 6개 config만 `structure.presentation: domestic-home-v2`로 선택 적용한다.
- 기존 wrapper URL, competition ID, 원본 data.json, 경기/순위 계산, 팀 상세/선수명단 링크는 변경하지 않는다.
- 공통 loader의 선택적 후처리 훅과 독립 CSS/JS를 사용한다. 기존 domestic v1 엔진을 복제하지 않는다.
- 국제·프로·종합대회 및 CBS의 데이터와 표시 설정은 변경하지 않는다.

## 화면 규칙

- 홈과 이어지는 밝은 배경, 남자 네이비/여자 로즈, 기존 성별 메인 이미지.
- 한눈에 보기: 참가대학/등록 경기/예선 조 편성 카드는 기존 해당 view로 이동하는 전체 영역 링크. 경기일 달력, 최종순위, 참가팀 요약.
- 달력 경기일 선택: 실제 경기와 세트별 점수, 일정 페이지 링크. 키보드/네이티브 dialog 지원.
- 참가대학: 실제 조편성이 있으면 조별 묶음 + 조 내 가나다순. 조편성 없는 대회는 전체 가나다순. 기존 대학 상세 경로 유지.
- 최종순위: 공통 엔진의 사다리, 부전승, 최종순위/예선 종합순위 계산 유지. 좁은 화면에서도 사다리를 유지하고 대진표 영역만 가로 스크롤.
- 인쇄는 기존 렌더러를 사용한다.

## 2026-10-26 · 달력 기준 월·예선 종합순위 수정

- 한눈에 보기 달력은 진행 중 한국시간의 현재 월, 종료 후 마지막 등록 경기의 월, 시작 전 첫 월을 기본 표시한다. 종료된 대회는 예정 종료일보다 마지막 경기일을 우선한다. 사용자의 수동 월 이동은 유지한다.

- 위의 ‘계산 유지’는 산식과 데이터 보존을 의미하며, 예선 이후 경기까지 더하던 잘못된 집계 범위는 이 규칙으로 수정한다.

## 2026-10-26 · 중·고 개별 대회 적용

- 사용자 운영 반영 요청으로 CBS배·IBK배·대통령배·익산·삼척·춘계 6개 대회, 남고/여고/남중/여중 24개 view에 같은 `domestic-home-v2`를 적용한다. 앞선 CBS/중·고 개별 대회 제외 범위를 이 24개 config에 한해 대체한다.
- 공통 엔진을 복제하지 않는다. 5개 legacy 대회는 DATA ONLY 생성기로 config/data를 만들고, CBS는 기존 config/data의 표시 설정만 확장한다. 예전 HTML 주소와 한글 division/탭 북마크는 새 정식 주소로 연결한다.
- `divisionLinks`와 `structure.divisionKey/divisionLabel/audience`로 네 부문을 선택한다. 탭을 유지하며 전환하고, 대학용 링크 대신 중·고 허브 및 해당 학교의 경기 기록으로 이동한다. 등록 선수 Snapshot이 없는 대회에 대학 명단 링크를 만들지 않는다.
- 조가 확인된 학교는 조별/조 내 가나다순, 미확인 조는 별도 표기, CBS는 전체 가나다순이다. 삼척의 조 순서는 기존 원본 bundle의 조 순서를 보존한다. 기존 alias manifest만 적용하고 새 Master ID를 발급하지 않는다.
- 모바일 조별순위는 학교명·승패 아래 승점/세트 득실비/점수 득실비를 나눠 표시한다. 숫자는 17px이며 페이지 가로 넘침 없이 전 항목을 읽을 수 있다. PC는 두 조씩 표시한다.
- 결선은 실제 다음 경기 참가 팀으로 사다리를 연결하고 기존 부전승을 표시한다. 일반 대진 연결은 실선, 부전승 연결은 기존 금색 점선을 사용한다. 중·고 경기 점수는 중립 짙은 회색을 사용한다.
- 원문 스코어와 세트 점수 불일치 4건은 원문을 보존하고 `reportedSets`/`scoreNote`로 표시한다. 정상 score 검증 계약은 완화하지 않는다. CBS의 미검수 조 편성·결선 연결은 만들지 않고 안내한다.
- 중·고 허브의 경기 수/입상팀 요약은 같은 상세 data에서 생성한다. 총 등록 600경기(기존 486 + CBS 기존 등록 114)이며 CBS는 부분 기록 상태를 명시한다.
- 검수·복구: [중·고 템플릿 적용 보고서](validation/school-domestic-home-v2-20261026.md).

## 2026-10-26 · PC 조 카드와 열 너비

- PC(901px 이상): 조 카드는 `repeat(2, minmax(0, 1fr))`, 카드 간격 16px. 마지막 조가 홀수로 남아도 반폭을 유지한다. 고성·단양·U리그·중고의 공통 규칙이다.
- 헤더와 행은 동일한 7열: 순위 36px / 팀 가변 / 승·패·승점 각 36px / 세트득실비·점수득실비 각 88px. 열 간격은 6px, 팀명 오른쪽은 추가 14px 여백.
- 긴 팀명은 자연스럽게 줄바꿈하며 말줄임/잘림을 사용하지 않는다. 득실비 제목의 b/small은 같은 줄에서 이어서 표시한다.
- 작은 PC 창에서는 카드 안의 최소 480px 표만 가로 스크롤한다. 모바일과 인쇄 레이아웃, 기존 17px 글씨 크기는 유지한다.
