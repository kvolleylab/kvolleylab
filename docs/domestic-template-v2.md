# Domestic Template v2 — Home presentation

2026-10-24 사용자 운영 반영 요청에 따라 홈 디자인과 승인된 국내대회 시안을 공통 Competition Engine v2 위에 적용한다.

## 적용 범위

- 고성·단양·대학 U-리그 2026 남대부/여대부, 총 6개 config만 `structure.presentation: domestic-home-v2`로 선택 적용한다.
- 기존 wrapper URL, competition ID, 원본 data.json, 경기/순위 계산, 팀 상세/선수명단 링크는 변경하지 않는다.
- 공통 loader의 선택적 후처리 훅과 독립 CSS/JS를 사용한다. 기존 domestic v1 엔진을 복제하지 않는다.
- 국제·프로·종합대회 및 CBS의 데이터와 표시 설정은 변경하지 않는다.

## 화면 규칙

- 홈과 이어지는 밝은 배경, 남자 네이비/여자 로즈, 기존 성별 메인 이미지.
- 한눈에 보기: 참가대학/등록 경기/예선 조 편성 카드는 기존 해당 view로 이동하는 전체 영역 링크. 경기일 달력, 최종순위, 참가팀 요약.
- 달력 경기일 선택: 실제 경기와 세트별 점수, 일정 페이지 링크. 키보드/네이티브 dialog 지원.
- 참가대학: 실제 조편성이 있으면 조별 묶음 + 조 내 가나다순. 조편성 없는 대회는 전체 가나다순. 기존 대학 상세 경로 유지.
- 최종순위: 공통 엔진의 사다리, 부전승, 최종순위/예선 종합순위 계산 유지. 좁은 화면에서도 사다리를 유지하고 대진표 영역만 가로 스크롤.
- 인쇄는 기존 렌더러를 사용한다.

## 운영 및 롤백

기존 domestic-template-v1.md의 데이터/진출/색상 의미/선수명단 계약은 계속 적용한다. 여기서 명시한 홈형 화면 배치와 모바일 사다리만 v2 규칙이 우선한다.

롤백은 해당 대회 config의 presentation 속성을 제거하면 된다. 미선택 대회에는 훅이 아무 DOM 변경도 하지 않는다.

## 2026-10-26 · 대학 U-리그 적용

- 사용자의 같은 시안 적용 요청으로 U-리그 남녀 정식 경로에도 공통 v2 presentation을 선택 적용한다. 별도 U-리그 엔진/페이지를 만들지 않는다.
- 남자부 조별순위와 여자부 단일 리그순위의 명칭·산식·데이터를 유지한다. 단일리그 한눈에 보기 순위 카드는 리그 참가 팀 수와 `groups` 링크를 사용한다.
- 참가대학은 남자부 A/B조 내 가나다순, 여자부 전체 가나다순. 단일리그를 가상의 조로 표시하지 않는다.
- 긴 순위 안내문은 카드 내부에서 줄바꿈한다. 모바일 Hero는 config의 기존 모바일 이미지를 사용하며, 색상과 PC/모바일 자산은 보존한다.
- 10/25 확정한 확대 글씨·달력·트로피·사다리 규칙을 적용한다. v1의 U-리그 글씨 크기 고정 규칙은 이 선택 적용 범위에서 최신 v2 규칙으로 대체한다.
- 검수: [U-리그 적용 보고서](validation/uleague-home-v2-20261026.md).

## 2026-10-26 · 달력 기준 월·예선 종합순위 수정

- 한눈에 보기 달력은 진행 중 한국시간의 현재 월, 종료 후 마지막 등록 경기의 월, 시작 전 첫 월을 기본 표시한다. 종료된 대회는 예정 종료일보다 마지막 경기일을 우선한다. 사용자의 수동 월 이동은 유지한다.
- 예선 종합순위는 standings에 정의된 예선 조의 두 팀이 같은 조에서 치른 경기만 계산한다. U-리그 6강리그 및 토너먼트 경기는 제외한다. 기존 승률 → 세트 득실비 → 점수 득실비 산식은 유지한다.
- 위의 ‘계산 유지’는 산식과 데이터 보존을 의미하며, 예선 이후 경기까지 더하던 잘못된 집계 범위는 이 규칙으로 수정한다.
- 검수: [달력·예선 종합순위 보고서](validation/uleague-preliminary-calendar-20261026.md).

## 2026-10-26 · U-리그 6강리그에서 4강까지 연결

- 남자 U-리그의 최종순위 탭에서 기존 최종 1~4위 카드와 4강 사다리 사이에 `6강리그 최종순위`를 표시한다. 예선 → 6강리그 → 4강·결승 흐름과 실제 준결승 조합을 함께 보여준다.
- `structure.knockout.leagueStage`의 stage/ranking/advanceCount로 선택한다. 현재 남자 U-리그 config만 `6강리그`/`kusf`/4를 사용한다. 여자부 및 다른 대회에는 새 표를 만들지 않는다.
- 해당 단계의 기존 경기만 집계하고, KUSF 공식 규정의 승점 → 승수 → 점수 득실비 → 세트 득실비 → 동률 팀 간 성적을 사용한다. 예선 종합순위의 별도 산식과 섞지 않는다. 진출 배지는 실제 준결승 참가 팀에 표시한다.
- PC는 표, 모바일은 같은 표 데이터를 학교별 카드로 표시한다. 대학명/본문 수치 크기는 각각 17px/15px이며 실제 팀 경기기록 링크를 유지한다.
- 검수: [6강리그 순위 연결 보고서](validation/uleague-six-league-20261026.md).

## 2026-10-26 · 중·고 개별 대회 적용

- 사용자 운영 반영 요청으로 CBS배·IBK배·대통령배·익산·삼척·춘계 6개 대회, 남고/여고/남중/여중 24개 view에 같은 `domestic-home-v2`를 적용한다. 앞선 CBS/중·고 개별 대회 제외 범위를 이 24개 config에 한해 대체한다.
- 공통 엔진을 복제하지 않는다. 5개 legacy 대회는 DATA ONLY 생성기로 config/data를 만들고, CBS는 기존 config/data의 표시 설정만 확장한다. 예전 HTML 주소와 한글 division/탭 북마크는 새 정식 주소로 연결한다.
- `divisionLinks`와 `structure.divisionKey/divisionLabel/audience`로 네 부문을 선택한다. 탭을 유지하며 전환하고, 대학용 링크 대신 중·고 허브 및 해당 학교의 경기 기록으로 이동한다. 등록 선수 Snapshot이 없는 대회에 대학 명단 링크를 만들지 않는다.
- 조가 확인된 학교는 조별/조 내 가나다순, 미확인 조는 별도 표기, CBS는 전체 가나다순이다. 삼척의 조 순서는 기존 원본 bundle의 조 순서를 보존한다. 기존 alias manifest만 적용하고 새 Master ID를 발급하지 않는다.
- 모바일 조별순위는 학교명·승패 아래 승점/세트 득실비/점수 득실비를 나눠 표시한다. 숫자는 17px이며 페이지 가로 넘침 없이 전 항목을 읽을 수 있다. PC는 두 조씩 표시한다.
- 결선은 실제 다음 경기 참가 팀으로 사다리를 연결하고 기존 부전승을 표시한다. 일반 대진 연결은 실선, 부전승 연결은 기존 금색 점선을 사용한다. 중·고 경기 점수는 중립 짙은 회색을 사용한다.
- 원문 스코어와 세트 점수 불일치 4건은 원문을 보존하고 `reportedSets`/`scoreNote`로 표시한다. 정상 score 검증 계약은 완화하지 않는다. CBS의 미검수 조 편성·결선 연결은 만들지 않고 안내한다.
- 중·고 허브의 경기 수/입상팀 요약은 같은 상세 data에서 생성한다. 총 등록 600경기(기존 486 + CBS 기존 등록 114)이며 CBS는 부분 기록 상태를 명시한다.
- 검수·복구: [중·고 템플릿 적용 보고서](validation/school-domestic-home-v2-20261026.md).
