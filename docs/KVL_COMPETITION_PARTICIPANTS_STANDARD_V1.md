# K-Volley Lab Competition Participants Standard v1

## 목적
국제대회·국내대회의 참가 단위(참가국/참가팀/참가대학/참가학교)와 그 안의 선수명단을 공정하고 일관된 순서·데이터·인쇄 방식으로 표시하기 위한 공통 기준이다.

## 참가 단위 정렬 원칙
1. 조별리그가 있는 대회는 **공식 조 순서(A→B→C… 또는 대회 공식 순서)** 를 먼저 따른다.
2. 같은 조 안에서는 **공식 조추첨 결과 또는 공식 엔트리/대회 자료에 표시된 순서** 를 유지한다.
3. 공식 자료에서 조 내부 순서를 확인할 수 없을 때만 **공식 영문 국가/팀명 알파벳순** 을 사용한다.
4. 개최국, 대한민국, 현재 순위, 성적, 인기, KVL 추천을 이유로 참가국 선택 순서를 앞당기지 않는다.
5. 순위·진출 여부는 `조별순위/최종순위` 화면에서 표현하고, `참가국` 화면의 기본 정렬에는 영향을 주지 않는다.

## 참가국 페이지 기본 구조
- 상단: 조별 참가국 선택 영역
- 선택 국가 헤더: 국기 / 국가명 / 영문명 / 코드 / 조 / 등록 인원
- 등록 선수명단: `등번호 | 영문명 | 한글명 | POS | 생년월일 | 키 | 해당 시즌 소속팀 | Volleybox`
- 국제대회는 선수명단을 별도 최상위 메뉴로 분리하지 않고 **참가국 페이지 안의 핵심 콘텐츠** 로 제공하는 것을 기본값으로 한다.

## Volleybox 표시 기준
- 검증된 선수 프로필 URL이 있을 때만 `VB↗` 버튼을 표시한다.
- URL이 없거나 동일인 검증이 끝나지 않았으면 `—` 로 표시한다.
- 검색 결과 URL이나 추정 URL을 자동 생성하지 않는다.
- Volleybox는 외부 프로필 보조 링크이며 공식 대회 등록정보보다 우선하지 않는다.

## 시즌 소속팀 데이터 구조
예: 2026-27 시즌

- `club`: 소속팀명
- `status`: `CONFIRMED | REPORTED | FREE_AGENT | UNKNOWN`
- `source`: 근거 URL
- `checkedAt`: 최종 확인일

### 공개 규칙
- `CONFIRMED`: 팀명 공개
- `FREE_AGENT`: `FA / 무소속` 공개
- `REPORTED`: 내부 추적만 유지하고 홈페이지는 `미확인`
- `UNKNOWN`: 홈페이지는 `미확인`

`미정`이라는 표현은 선수가 아직 계약을 결정하지 않았다는 의미로 오해될 수 있으므로 사용하지 않는다.

## MASTER 권장 필드
각 국가/팀 선수 시트에 아래 필드를 유지한다.

- `26-27 소속팀`
- `소속팀 확인상태`
- `소속팀 출처 URL`
- `소속팀 최종확인일`
- `소속팀 비고`

## 인쇄 기준
- 선수명단 인쇄는 **A4 가로** 를 기본으로 한다.
- **1개 참가국/팀 = 1페이지** 안에 들어오도록 구성한다.
- `선택 국가 인쇄`: 현재 선택한 1개국만 1페이지로 인쇄한다.
- `전체 인쇄`: 공식 참가국 정렬 순서대로 모든 국가를 한 번에 인쇄하되 각 국가마다 새 페이지를 시작한다.
- 인쇄물에는 내부 관찰메모·연봉·신뢰도·내부 검수 필드를 넣지 않는다.
- 인쇄 표에는 `등번호 | 영문명 | 한글명 | POS | 생년월일 | 키 | 시즌 소속팀`을 기본으로 한다.

## 데이터 우선순위
1. 대회 공식 엔트리/경기 등록
2. 국가협회·구단·리그 공식 발표
3. 신뢰도 높은 보도자료
4. Volleybox 등 보조 데이터베이스

공식 자료와 외부 프로필 값이 충돌하면 공식 대회/구단 자료를 우선한다.
